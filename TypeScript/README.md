# TypeScript 학습 순서

이 폴더는 **기초 타입 → 함수와 객체 → 제네릭 → 고급 타입 → 클래스 → 프로젝트 설정 → 선언 파일 → 타입 시스템 사고방식과 오류 읽기** 순서로 학습하도록 구성했습니다.

처음 공부한다면 폴더 이름 앞의 번호를 따라 `01`부터 `08`까지 차례대로 읽습니다. 이미 배운 내용을 복습할 때는 아래 표의 핵심 질문을 보고 필요한 문서부터 찾아가도 됩니다.

## 이 순서로 보는 이유

1. `01`에서 타입을 읽고 작성하는 기본 문법을 익힙니다.
2. `02`에서 실제 코드에서 가장 자주 만나는 함수와 객체에 타입을 적용합니다.
3. `03`에서 여러 타입에 공통으로 사용할 수 있는 제네릭과 타입 연산자를 배웁니다.
4. `04`에서 제네릭과 타입 연산자를 바탕으로 조건부 타입, 매핑된 타입 등 고급 기능을 익힙니다.
5. `05`에서 앞에서 배운 객체 타입과 제네릭을 클래스 설계에 연결합니다.
6. `06`에서 작성한 코드를 여러 파일과 실제 프로젝트 단위로 관리하는 방법을 배웁니다.
7. `07`에서 JavaScript 라이브러리와 TypeScript 프로젝트의 경계를 선언 파일로 연결하고, 타입을 생성·배포·진단하는 흐름을 익힙니다.
8. `08`에서 앞서 배운 문법을 타입 시스템의 판단 기준으로 다시 연결하고, 프로젝트 오류를 실제 타입과 기대 타입의 차이로 읽는 연습을 합니다.

## 초보자를 위한 공부 방법

각 문서를 읽을 때 다음 과정을 반복합니다.

1. **핵심 개념 정리**를 먼저 읽고 오늘 배울 범위를 파악합니다.
2. **본문 정리**의 예제는 눈으로만 보지 말고 직접 입력해 봅니다.
3. 예제의 타입이나 값을 하나씩 바꾸고 오류 메시지가 어떻게 달라지는지 확인합니다.
4. **적용 관점에서 다시 보기**와 **요약 정리**를 읽으며 핵심을 자신의 말로 설명합니다.
5. 문서 제목 옆의 질문에 답하기 어렵다면 다음 문서로 넘어가기 전에 해당 내용을 다시 봅니다.

## 복습할 때 확인할 것

- `any` 대신 `unknown`과 타입 좁히기를 사용할 수 있는가?
- 함수의 매개변수와 반환값에 적절한 타입을 붙일 수 있는가?
- `type`, `interface`, 유니언, 교차 타입의 쓰임을 구분할 수 있는가?
- 제네릭이 단순히 타입을 받는 문법이 아니라 타입 관계를 보존한다는 점을 설명할 수 있는가?
- 조건부 타입과 매핑된 타입이 어떤 문제를 해결하는지 설명할 수 있는가?
- 모듈 경계와 `tsconfig.json`의 주요 설정이 빌드 결과에 어떤 영향을 주는지 설명할 수 있는가?
- `.d.ts`, `declare`, `@types`의 역할을 구분하고 타입이 없는 패키지에 로컬 선언을 작성할 수 있는가?
- 타입 오류에서 실제 타입과 기대 타입을 구분하고 가장 안쪽의 불일치를 찾을 수 있는가?
- 외부 데이터를 `unknown`으로 받아 검증된 내부 타입으로 변환할 수 있는가?
