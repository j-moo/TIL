# IoT 학습 로드맵

사물 인터넷(IoT) 장치가 보낸 데이터는 어떤 과정을 거쳐 앱의 측정값이 될까? 첫 주제는 저전력 블루투스(BLE)다. 장치에 연결하는 일, 필요한 값을 찾는 일, 받은 바이트에 의미를 부여하는 일을 나누어 살펴본다.

## 학습 순서

| 순서 | 주제 | 핵심 질문 | 노트 |
| ---: | --- | --- | --- |
| 01 | BLE GATT로 센서 값 읽기 | 어떤 특성에서 값을 받아야 하며, 알림으로 받은 바이트가 어떤 측정값인지 어떻게 알 수 있을까? | [특성 발견부터 알림 바이트 해석까지](./01_11_19_BLE_GATT_and_Sensor_Data/11_19_BLE_GATT_and_Sensor_Data.md) |

바이트와 바이트 순서가 낯설다면 [문자열·인코딩의 바이트 표현](../Algorithm/02_06_String/02_06_String.md)에서 먼저 복습할 수 있다. 센서 값은 문자열이 아닐 수도 있으므로, 01에서는 같은 바이트를 어떤 규칙으로 숫자로 읽는지에 집중한다.
