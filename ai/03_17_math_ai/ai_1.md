## 1. 들어가며

머신러닝을 처음 배우면 모델 이름보다 먼저 두 가지를 구분해야 한다.

1. 모델에 무엇을 입력하고 무엇을 예측하려는가?
2. 예측이 잘됐는지 어떤 기준으로 판단하는가?

예를 들어 집값 예측에서는 면적과 위치가 입력 특성이 되고 집값이 정답이 된다. 스팸 메일 분류에서는 메일의 단어나 발신 정보가 입력 특성이고 스팸 여부가 정답이다.

```text
데이터 준비
→ 입력 특성과 정답 구분
→ 모델 학습
→ 검증 데이터로 모델 선택
→ 테스트 데이터로 최종 성능 평가
```

## 2. 핵심 개념 정리

```text
인공지능
└─ 머신러닝
   └─ 딥러닝
```

- **인공지능(AI)**: 인식, 추론, 계획, 예측처럼 지능적인 작업을 수행하는 시스템과 연구 분야
- **머신러닝(ML)**: 규칙을 모두 직접 코딩하지 않고 데이터에서 패턴을 학습하는 AI 접근법
- **딥러닝(DL)**: 여러 층의 신경망을 사용하는 머신러닝 방법

세 용어는 서로 대립하는 것이 아니라 포함 관계에 가깝다.

## 3. 본문 정리

### 3.1 Feature와 Label

`Feature`는 모델이 예측할 때 사용하는 입력 정보다. `Label` 또는 `Target`은 모델이 맞히려는 정답이다.

| 문제 | Feature | Label |
|---|---|---|
| 집값 예측 | 면적, 방 수, 위치 | 집값 |
| 스팸 분류 | 단어 빈도, 발신 정보 | 스팸 여부 |
| 시험 점수 예측 | 공부 시간, 출석률 | 시험 점수 |

Feature가 하나라고 해서 데이터 하나만 사용한다는 뜻은 아니다. 여러 샘플이 있고, 각 샘플을 설명하는 입력 변수가 하나라는 뜻이다.

---

### 3.2 지도학습의 회귀와 분류

지도학습은 입력과 정답의 쌍을 이용해 새로운 입력의 정답을 예측하는 규칙을 학습한다.

#### 회귀

연속적인 수치를 예측한다.

- 집값
- 매출액
- 온도
- 시험 점수

#### 분류

미리 정한 범주를 예측한다.

- 스팸 또는 정상
- 질병 있음 또는 없음
- 고양이, 개, 새

⚠️ 주의: 로지스틱 회귀는 이름에 `회귀`가 있지만 기본적으로 분류에 사용하는 모델이다.

---

### 3.3 데이터는 학습·검증·테스트로 나눈다

```text
학습 데이터
→ 모델 파라미터 학습

검증 데이터
→ 모델과 하이퍼파라미터 선택

테스트 데이터
→ 선택이 끝난 모델의 최종 일반화 성능 확인
```

테스트 데이터로 여러 모델을 반복해서 고르면 테스트 결과에 맞춘 선택이 된다. 그러면 테스트 점수가 실제 새로운 데이터의 성능을 과대평가할 수 있다.

데이터가 충분하지 않을 때는 교차 검증으로 여러 분할의 검증 결과를 함께 볼 수 있다.

---

### 3.4 회귀 평가 지표

#### MSE

평균제곱오차는 실제값과 예측값의 차이를 제곱한 뒤 평균낸다.

```text
오차 = 실제값 - 예측값
MSE = 오차 제곱의 평균
```

오차를 제곱하므로 큰 오차에 더 큰 영향을 받는다. 값이 작을수록 예측값이 실제값에 가깝다.

#### R²

결정계수 R²는 단순히 평균으로 예측하는 기준 모델과 비교해 회귀 모델이 변동을 얼마나 설명하는지 나타낸다.

- `1`: 관측값을 완벽하게 설명
- `0`: 평균으로만 예측한 것과 비슷
- 음수: 평균으로 예측한 것보다 성능이 나쁨

⚠️ 주의: R²는 항상 0과 1 사이인 지표가 아니다. 절편 포함 여부와 평가 데이터에 따라 음수가 될 수 있다.

---

### 3.5 분류 평가와 혼동행렬

이진 분류의 결과는 네 경우로 나눌 수 있다.

| 실제 / 예측 | 양성 예측 | 음성 예측 |
|---|---:|---:|
| 실제 양성 | TP | FN |
| 실제 음성 | FP | TN |

- **정확도**: 전체 중 맞춘 비율
- **정밀도**: 양성이라고 예측한 것 중 실제 양성의 비율
- **재현율**: 실제 양성 중 모델이 찾아낸 비율

질병 환자가 전체의 1%인 데이터에서 모든 사람을 정상이라고 예측해도 정확도는 99%가 된다. 따라서 불균형 데이터에서는 정확도 하나만 보면 안 된다.

```python
from sklearn.metrics import classification_report, confusion_matrix

# y_true는 실제 정답, y_pred는 모델의 예측이다.
print(confusion_matrix(y_true, y_pred))
print(classification_report(y_true, y_pred))
```

### 3.6 일반화, 과적합과 과소적합

모델의 목표는 학습 데이터를 외우는 것이 아니라 처음 보는 데이터에도 잘 작동하는 것이다. 이를 일반화라고 한다.

#### 과적합

학습 데이터의 잡음까지 지나치게 학습한 상태다.

```text
학습 성능은 매우 좋음
테스트 성능은 상대적으로 나쁨
```

#### 과소적합

모델이 너무 단순하거나 학습이 부족해 중요한 패턴을 잡지 못한 상태다.

```text
학습 성능도 나쁨
테스트 성능도 나쁨
```

과적합을 줄이기 위해 더 많은 데이터, 규제, 단순한 모델, 데이터 증강과 교차 검증 등을 고려할 수 있다. 해결 방법은 데이터와 모델에 따라 달라진다.

## 5. 배운 점 / 확장 포인트

### 5.1 새로 이해한 것

평가 지표는 모델이 학습할 때 사용하는 손실함수와 반드시 같을 필요는 없다. 학습에서는 최적화하기 쉬운 손실을 쓰고, 최종 평가는 실제 목표를 잘 나타내는 여러 지표로 볼 수 있다.

### 5.2 다음 학습과의 연결

- 선형회귀와 최소제곱법
- 로지스틱 회귀와 확률
- 경사하강법
- 교차 검증
- 특성 스케일링과 데이터 전처리

### 5.3 더 확인할 주제

- ROC-AUC와 PR-AUC
- 다중 분류의 macro·micro 평균
- 데이터 누수
- 회귀의 MAE와 RMSE

## 6. 요약 정리

- 머신러닝은 데이터에서 예측 규칙을 학습한다.
- Feature는 입력, Label은 예측할 정답이다.
- 회귀는 연속값, 분류는 범주를 예측한다.
- 검증 데이터는 모델 선택, 테스트 데이터는 최종 평가에 사용한다.
- MSE는 큰 회귀 오차에 더 큰 영향을 준다.
- R²는 음수가 될 수 있다.
- 불균형 분류에서는 정확도 외에 정밀도와 재현율도 확인한다.
- 일반화 성능을 위해 과적합과 과소적합을 구분해야 한다.

🧠 기억할 것: 좋은 모델은 학습 데이터를 잘 외운 모델이 아니라 **처음 보는 데이터에서도 목적에 맞는 성능을 내는 모델**이다.
