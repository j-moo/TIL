# 선형회귀, 로지스틱 회귀와 경사하강법

- 🎯 글의 목표: 선형회귀와 로지스틱 회귀가 무엇을 예측하는지 구분하고, 손실함수와 경사하강법이 모델 학습에 어떻게 연결되는지 설명할 수 있다.
- 🧩 핵심 키워드: Linear Regression, RSS, Least Squares, Logistic Regression, Sigmoid, Cross-Entropy, Gradient Descent, Learning Rate, SGD
- ⭐ 중요도: ★★★★★ — 많은 머신러닝 모델의 학습 원리를 이해하는 출발점이다.
- 📝 한눈에 보는 내용: 모델은 입력으로 예측을 만들고 손실함수로 오차를 측정한다. 경사하강법은 손실이 작아지는 방향으로 파라미터를 반복해서 갱신한다.
- 🔗 관련 노트: [NumPy 선형회귀와 로지스틱 회귀](./NumPy_선형회귀와_로지스틱회귀_통합_강의노트.md)

## 1. 들어가며

머신러닝 모델의 학습은 다음 네 질문으로 정리할 수 있다.

```text
어떤 값을 예측하는가?
→ 모델

예측이 얼마나 틀렸는가?
→ 손실함수

어느 방향으로 바꿔야 하는가?
→ 기울기

얼마나 크게 바꿀 것인가?
→ 학습률
```

선형회귀와 로지스틱 회귀는 목적이 다르지만 이 공통 흐름을 이용해 이해할 수 있다.

---

## 2. 핵심 개념 정리

| 구분 | 선형회귀 | 로지스틱 회귀 |
|---|---|---|
| 기본 목적 | 연속값 예측 | 범주 또는 양성 확률 예측 |
| 예시 | 매출, 집값 | 스팸 여부, 질병 여부 |
| 대표 출력 | 실수값 | 0과 1 사이 확률 |
| 대표 손실 | MSE 또는 RSS | 이진 교차 엔트로피 |

## 3. 본문 정리

### 3.1 단순선형회귀

단순선형회귀는 입력 하나와 출력 사이의 관계를 직선으로 표현한다.

```text
ŷ = β₀ + β₁x
```

- `x`: 입력 Feature
- `ŷ`: 모델의 예측
- `β₀`: 절편
- `β₁`: 기울기 또는 계수

실제 데이터는 완벽한 직선 위에 놓이지 않는다. 실제값 `y`와 예측값 `ŷ`의 차이를 잔차라고 한다.

```text
잔차 = y - ŷ
```

---

### 3.2 RSS와 최소제곱법

RSS는 `Residual Sum of Squares`, 즉 잔차제곱합이다.

```text
각 샘플의 잔차를 구한다.
→ 잔차를 제곱한다.
→ 모든 샘플의 값을 더한다.
```

잔차를 그대로 더하면 양수와 음수가 상쇄될 수 있다. 제곱하면 부호 문제를 없애고 큰 오차에 더 큰 벌점을 줄 수 있다.

최소제곱법은 RSS가 가장 작아지는 계수를 찾는 방법이다. 선형회귀는 행렬 계산으로 해를 구할 수도 있고, 경사하강법으로 반복해서 근사할 수도 있다.

---

### 3.3 다중선형회귀

입력 Feature가 여러 개면 다중선형회귀로 확장한다.

```text
ŷ = β₀ + β₁x₁ + β₂x₂ + ... + βₚxₚ
```

다른 Feature가 같다고 가정할 때 `βⱼ`는 `xⱼ`가 1 증가할 때 예측값이 평균적으로 얼마나 변하는지를 나타낸다.

⚠️ 주의: Feature 사이의 상관이 지나치게 높으면 계수 해석이 불안정해지는 다중공선성 문제가 생길 수 있다.

---

### 3.4 로지스틱 회귀는 분류 모델이다

선형식의 출력은 어떤 실수도 될 수 있다. 이 값을 시그모이드 함수에 통과시키면 0과 1 사이 값으로 바꿀 수 있다.

```text
선형 결합 z = β₀ + β₁x₁ + ...
→ sigmoid(z)
→ 양성 클래스일 확률
```

확률이 기준값 이상이면 양성, 미만이면 음성으로 분류할 수 있다. 기준값은 문제 목적에 따라 조정할 수 있다.

⚠️ 주의: 로지스틱 회귀의 파라미터를 학습할 때 일반적으로 MSE가 아니라 최대우도와 연결되는 교차 엔트로피 손실을 사용한다.

---

### 3.5 손실함수

손실함수는 모델의 예측이 정답과 얼마나 다른지 하나의 값으로 표현한다.

```text
파라미터
→ 예측
→ 손실 계산
→ 파라미터 갱신
```

손실값이 작아지는 방향으로 파라미터를 찾는 과정이 학습이다. 문제 유형과 모델에 따라 적절한 손실함수가 다르다.

---

### 3.6 경사하강법

경사하강법은 손실함수를 작게 만드는 방향으로 파라미터를 반복해서 갱신한다.

```text
1. 현재 파라미터에서 손실 계산
2. 파라미터에 대한 손실의 기울기 계산
3. 기울기의 반대 방향으로 이동
4. 종료 조건까지 반복
```

업데이트 식의 핵심은 다음과 같다.

```text
새 파라미터 = 현재 파라미터 - 학습률 × 기울기
```

기울기는 손실이 가장 빠르게 증가하는 방향을 가리킨다. 따라서 손실을 줄이려면 반대 방향으로 이동한다.

---

### 3.7 학습률

학습률은 한 번의 업데이트에서 얼마나 크게 이동할지 결정한다.

```text
너무 큰 학습률
→ 최솟값을 지나치거나 학습이 불안정

너무 작은 학습률
→ 학습이 매우 느리거나 좋은 지점에 도달하기 전에 종료
```

학습률은 모델이 자동으로 학습하는 일반 파라미터와 구분되는 하이퍼파라미터다.

---

### 3.8 Batch, SGD와 Mini-batch

기울기를 계산할 때 사용하는 데이터 양에 따라 구분한다.

| 방식 | 한 번의 업데이트에 사용하는 데이터 |
|---|---|
| Batch Gradient Descent | 전체 학습 데이터 |
| Stochastic Gradient Descent | 샘플 하나 |
| Mini-batch Gradient Descent | 일부 샘플 묶음 |

딥러닝 실무에서 `SGD`라는 이름은 미니배치와 함께 사용하는 최적화 알고리즘을 가리키는 경우도 많다. 개념을 설명할 때는 엄밀한 정의와 실제 라이브러리 사용 관례를 구분한다.

---

### 3.9 볼록 최적화와 비볼록 최적화

기본 선형회귀의 제곱오차처럼 볼록한 목적함수는 지역 최솟값이 곧 전역 최솟값이다.

하지만 “2차 미분이 항상 양수”만을 모든 볼록 문제의 정의로 외우면 안 된다. 2차 미분 조건은 미분 가능한 1차원 함수에서 볼록성을 판단하는 충분조건으로 사용할 수 있지만, 더 일반적인 볼록성 정의는 두 점 사이의 선분과 함수값의 관계를 사용한다.

신경망의 손실 표면은 일반적으로 비볼록하므로 경사하강법이 항상 전역 최솟값을 보장하지 않는다.

모델, 손실함수와 최적화 알고리즘은 서로 다른 역할을 한다. 선형회귀는 예측식을 정의하고, 손실함수는 예측 오차를 측정하며, 경사하강법은 손실이 작아지도록 계수를 바꾼다.

## 6. 요약 정리

- 선형회귀는 연속값을 예측한다.
- RSS는 잔차의 제곱을 합한 값이다.
- 로지스틱 회귀는 시그모이드로 양성 확률을 모델링하는 분류 방법이다.
- 손실함수는 예측이 얼마나 틀렸는지 측정한다.
- 경사하강법은 기울기의 반대 방향으로 파라미터를 갱신한다.
- 학습률은 한 번에 이동하는 크기를 정한다.
- Batch, SGD, Mini-batch는 기울기 계산에 사용하는 데이터 양이 다르다.

🧠 기억할 것: `모델로 예측 → 손실 계산 → 기울기 계산 → 파라미터 갱신`이 학습의 기본 반복이다.

## 7. 미니 퀴즈

1. RSS는 왜 잔차를 제곱하는가?
2. 선형회귀와 로지스틱 회귀의 출력 목적은 어떻게 다른가?
3. 경사하강법에서 기울기의 반대 방향으로 이동하는 이유는 무엇인가?
4. 학습률이 너무 크거나 작으면 어떤 문제가 생기는가?
5. SGD와 Mini-batch Gradient Descent를 엄밀하게 구분하면 어떻게 다른가?

<details>
<summary>정답과 해설</summary>

1. 잔차의 부호가 상쇄되는 것을 막고 큰 오차에 더 큰 벌점을 주기 위해서다.
2. 선형회귀는 연속값, 로지스틱 회귀는 범주에 속할 확률을 예측한다.
3. 기울기가 손실이 증가하는 방향을 나타내기 때문이다.
4. 너무 크면 발산하거나 불안정하고, 너무 작으면 학습이 지나치게 느리다.
5. SGD는 샘플 하나, Mini-batch는 일부 샘플 묶음으로 한 번의 기울기를 계산한다.
