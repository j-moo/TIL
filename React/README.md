# React 학습 로드맵

React를 처음 공부할 때 개념, 실행 환경, 주변 생태계를 한꺼번에 외우지 않도록 세 단계로 나누었다.

## 권장 학습 순서

| 순서 | 주제 | 학습 목표 | 노트 |
|---|---|---|---|
| 1 | React 핵심 개념 | 컴포넌트·props·state·렌더링·JSX의 관계 이해 | [React 입문](./07_26_React_Introduction/07_26_React_Introduction.md) |
| 2 | 프로젝트 실행 환경 | Vite 프로젝트 생성과 `index.html → main.jsx → App` 흐름 이해 | [Vite로 React 프로젝트 시작하기](./07_26_React_Introduction/07_26_React_Project_Setup_with_Vite.md) |
| 3 | 생태계와 도구 선택 | SPA, 라우터, 프레임워크, React Native의 역할 구분 | [React 생태계와 도구 선택](./07_26_React_Introduction/07_26_React_Ecosystem.md) |

## 복습 기준

각 노트를 읽은 뒤 다음 질문에 답할 수 있는지 확인한다.

1. React에서 데이터가 UI로 바뀌는 흐름을 설명할 수 있는가?
2. 로컬 프로젝트가 어떤 파일부터 실행되는지 설명할 수 있는가?
3. React, Vite, React Router, Next.js의 역할을 구분할 수 있는가?

세 질문 중 막히는 부분이 있으면 해당 노트의 `요약 정리`와 `미니 퀴즈`부터 다시 확인한다.
