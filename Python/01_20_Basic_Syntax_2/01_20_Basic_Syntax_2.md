## 1. 들어가며

온라인 쇼핑몰의 장바구니를 만든다고 생각해 보자. 여러 상품을 담으려면 목록이 필요하고, 상품 이름과 가격을 연결하려면 이름표가 있는 저장 방식이 필요하다. 이미 담긴 상품인지 확인하거나 할인 조건을 검사할 때는 값의 포함 여부와 여러 조건을 계산해야 한다.

값 하나만 다룰 때는 숫자나 문자열만으로 충분하지만, 실제 프로그램은 여러 값을 함께 관리한다. 파이썬은 데이터의 순서, 변경 가능성, 중복 허용 여부에 따라 서로 다른 컬렉션을 제공한다. 어떤 자료형을 고르느냐에 따라 코드의 의미와 처리 방식이 달라진다.

이번 강의는 먼저 여러 값을 저장하는 `list`, `tuple`, `range`, `dict`, `set`을 차례로 살펴본다. 이어서 값이 없음을 나타내는 `None`과 참·거짓을 나타내는 `bool`, 컬렉션의 공통 분류 기준을 정리한다.

그다음 서로 다른 타입을 계산에 맞게 바꾸는 형 변환을 배우고, 산술·비교·논리·멤버십·시퀀스 연산자를 연결한다. 마지막에는 논리 연산이 실제 값을 반환하는 단축 평가와 여러 줄 컬렉션을 안정적으로 작성하는 후행 쉼표까지 다룬다.

## 2. 핵심 개념 정리

이 강의가 해결하려는 첫 번째 질문은 **여러 값을 어떤 그릇에 담을 것인가**이다. 순서대로 저장하고 자유롭게 바꾸려면 리스트가 알맞다. 값을 바꾸지 못하게 고정하려면 튜플, 일정한 정수 흐름이 필요하면 `range`를 사용한다. 이름표로 값을 찾으려면 딕셔너리, 중복 없는 집합이 필요하면 세트를 선택한다.

두 번째 질문은 **자료형이 서로 다를 때 어떻게 계산할 것인가**이다. 파이썬이 안전한 범위에서 자동으로 타입을 맞추는 암시적 형 변환이 있고, 개발자가 `int()`, `str()`, `list()` 같은 함수를 호출해 직접 바꾸는 명시적 형 변환이 있다.

세 번째 질문은 **저장한 값을 어떻게 가공하고 판단할 것인가**이다. 산술 연산자는 수치를 계산하고, 비교 연산자는 관계를 `True`나 `False`로 만든다. 논리 연산자는 조건을 조합하며, 멤버십 연산자는 값의 포함 여부를 확인한다. 시퀀스의 `+`와 `*`는 연결과 반복이라는 별도 의미를 가진다.

마지막 질문은 **조건을 얼마나 정확하고 효율적으로 평가할 것인가**이다. `and`와 `or`는 결과가 확정되면 뒤쪽 표현식을 평가하지 않는다. 이 단축 평가를 이해하려면 파이썬이 어떤 값을 거짓으로 보는지, 그리고 논리 연산자가 항상 `bool`만 반환하는 것은 아니라는 사실을 함께 알아야 한다.

본문은 다음 흐름으로 이어진다.

1. 순서가 있는 컬렉션: 리스트, 튜플, `range`
2. 키 또는 집합 관계를 사용하는 컬렉션: 딕셔너리, 세트
3. 특별한 단일 값과 컬렉션 분류: `None`, `bool`, 가변·불변
4. 타입을 맞추는 형 변환
5. 데이터를 계산하고 판단하는 연산자
6. 조건 평가를 줄이는 단축 평가와 코드 형식을 돕는 후행 쉼표

## 3. 본문 정리

### 3.1 리스트: 순서가 있고 변경 가능한 저장소

리스트(`list`)는 여러 값을 순서대로 저장하는 **가변 시퀀스 자료형**이다. 장바구니처럼 항목의 순서가 있고 실행 중에 값을 추가·수정·삭제해야 하는 상황에 적합하다.

리스트는 대괄호 `[]` 안에 값을 쉼표로 구분해 만든다. 하나의 리스트 안에 숫자, 문자열, 불리언, 다른 리스트처럼 서로 다른 타입을 함께 넣을 수도 있다.

```python
# 빈 리스트를 만든다.
empty_list = []

# 서로 다른 타입의 값을 순서대로 저장한다.
my_list = [1, 'a', 3, 'b', 5]

# 리스트 안에 또 다른 리스트도 넣을 수 있다.
mixed_list = [1, 2, 3, 'Python', ['hello', 'world']]

print(my_list)    # [1, 'a', 3, 'b', 5]
print(mixed_list) # [1, 2, 3, 'Python', ['hello', 'world']]
```

각 값에는 왼쪽부터 `0`, `1`, `2`, ... 순서로 인덱스가 붙는다. 음수 인덱스는 오른쪽 끝부터 `-1`, `-2`, ... 순서로 센다. 따라서 원하는 위치의 값을 직접 꺼낼 수 있다.

### 3.2 시퀀스로서의 리스트: 인덱싱과 슬라이싱

리스트는 시퀀스이므로 문자열에서 사용한 인덱싱, 슬라이싱, 길이 확인을 그대로 사용할 수 있다. 인덱싱은 값 하나를 꺼내고, 슬라이싱은 범위를 잘라 새 리스트를 만든다.

```python
my_list = [1, 'a', 3, 'b', 5]

# 인덱스 1의 값 하나를 가져온다.
print(my_list[1])      # a

# 시작 인덱스 2부터 종료 인덱스 4 직전까지 가져온다.
print(my_list[2:4])    # [3, 'b']

# 시작을 생략하면 처음부터 인덱스 3 직전까지 가져온다.
print(my_list[:3])     # [1, 'a', 3]

# 종료를 생략하면 인덱스 3부터 끝까지 가져온다.
print(my_list[3:])     # ['b', 5]

# 세 번째 값인 step을 2로 두면 한 칸씩 건너뛴다.
print(my_list[::2])    # [1, 3, 5]

# step -1은 역순으로 순회하므로 리스트를 뒤집은 결과를 만든다.
print(my_list[::-1])   # [5, 'b', 3, 'a', 1]

# len은 리스트에 저장된 요소 수를 반환한다.
print(len(my_list))    # 5
```

슬라이스의 종료 인덱스는 포함되지 않는다. `[2:4]`는 인덱스 `2`, `3`까지만 선택한다는 뜻이다.

⚠️ 주의: 요소가 5개인 리스트의 유효한 양수 인덱스는 `0`부터 `4`까지다. `my_list[5]`처럼 범위를 벗어난 위치에 접근하면 `IndexError`가 발생한다. 슬라이싱은 범위를 조금 벗어나도 가능한 범위까지만 반환한다는 차이도 있다.

### 3.3 중첩 리스트: 안쪽 값에 단계적으로 접근하기

리스트가 다른 리스트를 값으로 가지면 **중첩 리스트**라고 한다. 표처럼 행과 열이 있거나, 그룹 안에 여러 항목이 들어 있는 구조를 표현할 때 사용한다.

안쪽 값에 접근할 때는 바깥쪽부터 한 단계씩 선택한다. 첫 번째 인덱스로 안쪽 리스트를 고른 뒤, 두 번째 인덱스로 그 리스트의 값을 고른다.

```python
my_list = [1, 2, 3, 'Python', ['hello', 'world']]

# 바깥 리스트에는 총 5개의 요소가 있다.
print(len(my_list))       # 5

# 인덱스 4로 안쪽 리스트를 고르고, -1로 마지막 문자열을 고른다.
print(my_list[4][-1])     # world

# -1은 안쪽 리스트, 1은 'world', 0은 첫 글자 'w'를 선택한다.
print(my_list[-1][1][0])  # w
```

`my_list[-1][1][0]`을 한 번에 읽으려 하면 복잡해 보인다. 먼저 `my_list[-1]`, 그 결과에서 `[1]`, 다시 그 결과에서 `[0]`을 적용한다고 나누어 읽으면 된다.

⚠️ 주의: 각 인덱스가 가리키는 값의 타입을 확인해야 한다. 문자열에 다시 인덱싱하면 글자 하나가 나오지만, 정수처럼 인덱싱할 수 없는 값에 `[]`를 이어 붙이면 `TypeError`가 발생한다.

### 3.4 리스트의 가변성: 만든 뒤 내용을 바꾸기

가변성(`mutability`)은 객체를 만든 뒤에도 그 내용을 변경할 수 있는 성질이다. 리스트는 같은 리스트를 유지한 채 특정 요소나 범위를 바꿀 수 있다.

```python
my_list = [1, 2, 3, 4, 5]

# 인덱스 1의 값 하나를 문자열로 교체한다.
my_list[1] = 'two'
print(my_list)  # [1, 'two', 3, 4, 5]

# 인덱스 2부터 4 직전까지를 두 문자열로 교체한다.
my_list[2:4] = ['three', 'four']
print(my_list)  # [1, 'two', 'three', 'four', 5]
```

인덱스 대입은 한 위치를 바꾸고, 슬라이스 대입은 여러 위치를 한꺼번에 바꾼다. 이 성질 때문에 리스트는 실행 중 항목이 변하는 장바구니나 작업 목록에 잘 맞는다.

⚠️ 주의: 슬라이스 대입 오른쪽에는 반복 가능한 값이 와야 한다. 또한 선택한 범위의 길이와 새 값의 개수가 달라도 리스트 길이가 늘거나 줄 수 있다. 단순 교체인지 구조 변경인지 의도를 분명히 해야 한다.

📌 핵심: 리스트는 **순서가 필요하고 내용을 계속 바꿔야 할 때** 선택하는 기본 컬렉션이다.

### 3.5 튜플: 순서가 있지만 변경할 수 없는 저장소

튜플(`tuple`)은 여러 값을 순서대로 저장하는 **불변 시퀀스 자료형**이다. 인덱싱과 슬라이싱은 리스트와 비슷하지만, 생성된 뒤 요소를 수정할 수 없다는 점이 결정적인 차이다.

일반적으로 소괄호 안에 값을 쉼표로 구분해 작성한다. 실제로 튜플을 만드는 기준은 괄호보다 쉼표다.

```python
# 요소가 없는 빈 튜플이다.
empty_tuple = ()

# 요소가 하나인 튜플에는 반드시 후행 쉼표가 필요하다.
single_tuple = (1,)

# 여러 타입을 함께 저장할 수 있다.
my_tuple = (1, 'a', 3, 'b', 5)

# 소괄호를 생략해도 쉼표 때문에 튜플이 만들어진다.
another_tuple = 1, 'hello', 3.14, True

print(single_tuple)  # (1,)
print(another_tuple) # (1, 'hello', 3.14, True)
```

`(1)`은 계산 순서를 묶은 정수 `1`일 뿐이다. `(1,)`처럼 쉼표가 있어야 요소 하나짜리 튜플로 해석된다.

### 3.6 시퀀스로서의 튜플과 불변성

튜플도 시퀀스이므로 인덱싱, 슬라이싱, `len()`을 사용할 수 있다. 슬라이싱의 결과는 리스트가 아니라 새 튜플이다.

```python
my_tuple = (1, 'a', 3, 'b', 5)

print(my_tuple[1])     # a
print(my_tuple[2:4])   # (3, 'b')
print(my_tuple[:3])    # (1, 'a', 3)
print(my_tuple[3:])    # ('b', 5)
print(my_tuple[::2])   # (1, 3, 5)
print(my_tuple[::-1])  # (5, 'b', 3, 'a', 1)
print(len(my_tuple))   # 5
```

그러나 인덱스에 새 값을 대입할 수는 없다.

```python
my_tuple = (1, 2, 3)

# 튜플은 불변이므로 아래 대입은 실패한다.
my_tuple[1] = 100
# TypeError: 'tuple' object does not support item assignment
```

불변성은 값이 의도치 않게 바뀌지 않도록 한다. 그래서 튜플은 여러 값을 한 묶음으로 전달하거나, 다중 할당과 값 교환, 함수의 여러 반환값을 다룰 때 자주 사용된다.

```python
# 오른쪽의 두 값을 튜플처럼 묶고 왼쪽 변수에 차례대로 푼다.
x, y = 10, 20
print(x)  # 10
print(y)  # 20

# 오른쪽에서 (y, x)를 먼저 만든 뒤 x와 y에 다시 풀어 값이 교환된다.
x, y = y, x
print(x, y)  # 20 10
```

⚠️ 주의: 튜플 자체가 불변이라는 말이 내부의 모든 객체까지 불변이라는 뜻은 아니다. 튜플 안에 리스트가 들어 있다면 튜플의 위치는 바꿀 수 없어도 그 리스트의 내용은 바뀔 수 있다. 이번 단계에서는 “튜플 요소를 다른 값으로 재할당할 수 없다”는 원칙을 먼저 기억한다.

### 3.7 range: 정수 시퀀스의 규칙 저장하기

`range`는 연속된 정수 시퀀스를 표현하는 불변 자료형이다. 모든 숫자를 리스트로 미리 저장하는 대신 시작, 종료, 간격이라는 규칙을 기억하므로 반복 횟수를 표현할 때 효율적이다.

기본 구문은 `range(start, stop, step)`이다. 인자 수에 따라 생략된 값이 정해진다.

| 형태 | 해석 | 예시 결과 |
|---|---|---|
| `range(stop)` | `start=0`, `step=1` | `range(5)` → `0, 1, 2, 3, 4` |
| `range(start, stop)` | `step=1` | `range(2, 5)` → `2, 3, 4` |
| `range(start, stop, step)` | 세 값을 모두 지정 | `range(2, 10, 2)` → `2, 4, 6, 8` |

`range` 객체를 그대로 출력하면 내부 숫자 목록이 아니라 규칙이 보인다. 실제 값을 확인하고 싶으면 학습 단계에서는 `list()`로 변환할 수 있다.

```python
my_range_1 = range(5)
my_range_2 = range(1, 10)
my_range_3 = range(5, 0, -1)

print(my_range_1)       # range(0, 5)
print(my_range_2)       # range(1, 10)
print(my_range_3)       # range(5, 0, -1)

print(list(my_range_1)) # [0, 1, 2, 3, 4]
print(list(my_range_2)) # [1, 2, 3, 4, 5, 6, 7, 8, 9]
print(list(my_range_3)) # [5, 4, 3, 2, 1]
```

### 3.8 range의 종료값과 증가·감소 규칙

`stop`은 결과에 포함되지 않는다. `range(1, 5)`는 1부터 5 **직전**까지이므로 `1, 2, 3, 4`를 만든다.

`step`의 부호는 진행 방향을 정한다. 양수면 증가하고 음수면 감소한다. 진행 방향과 `start`, `stop`의 관계가 맞지 않으면 오류가 아니라 빈 시퀀스가 만들어진다.

```python
# 1에서 시작해 5 직전까지 1씩 증가한다.
print(list(range(1, 5)))         # [1, 2, 3, 4]

# 기본 step은 양수인데 시작값이 더 크므로 진행할 수 없다.
print(list(range(5, 1)))         # []

# 음수 step을 주면 5에서 1을 향해 감소한다.
print(list(range(5, 1, -1)))     # [5, 4, 3, 2]

# 양수 step으로 홀수만 만든다.
print(list(range(1, 10, 2)))     # [1, 3, 5, 7, 9]

# 음수 step으로 2씩 감소한다.
print(list(range(10, 1, -2)))    # [10, 8, 6, 4, 2]
```

반복문에서는 `range`가 만든 정수를 차례대로 꺼내 사용한다.

```python
# 1부터 9까지 차례대로 출력한다.
for i in range(1, 10):
    print(i)

# 1, 3, 5, 7, 9만 차례대로 출력한다.
for i in range(1, 10, 2):
    print(i)
```

⚠️ 주의: `step`에는 `0`을 사용할 수 없다. 어느 방향으로도 진행할 수 없기 때문에 `range(1, 5, 0)`은 `ValueError`를 일으킨다.

📌 핵심: `range`는 종료값을 포함하지 않으며, `step`의 부호와 시작·종료 관계가 진행 방향을 결정한다.

### 3.9 딕셔너리: 키와 값의 연결

딕셔너리(`dict`)는 `key: value` 쌍으로 데이터를 저장하는 가변 컬렉션이다. 위치 번호가 아니라 의미 있는 이름표로 값을 찾고 싶을 때 사용한다. 상품 이름과 가격, 사람의 이름과 나이처럼 각 값에 의미가 있는 데이터에 적합하다.

중괄호 `{}` 안에서 키와 값을 콜론으로 연결하고, 각 쌍을 쉼표로 구분한다.

```python
# 빈 딕셔너리다.
empty_dict = {}

# 하나의 키-값 쌍을 저장한다.
my_dict_1 = {'key': 'value'}

# 값에는 숫자나 리스트 등 어떤 자료형도 사용할 수 있다.
my_dict_2 = {
    'apple': 12,
    'items': [1, 2, 3],
}

print(empty_dict) # {}
print(my_dict_1)  # {'key': 'value'}
print(my_dict_2)  # {'apple': 12, 'items': [1, 2, 3]}
```

키는 하나의 딕셔너리 안에서 고유해야 한다. 문자열, 숫자, 튜플처럼 변경 불가능하고 해시 가능한 값을 키로 사용할 수 있다. 리스트나 딕셔너리처럼 변경 가능한 값은 키로 사용할 수 없다. 값에는 어떤 자료형이든 올 수 있다.

현대 파이썬의 딕셔너리는 입력 순서를 보존하지만, 핵심 접근 방식은 여전히 순번이 아니라 키다. 딕셔너리를 리스트처럼 `my_dict[0]`으로 읽는다고 생각해서는 안 된다.

### 3.10 딕셔너리 값 접근·추가·변경

대괄호 안에 키를 넣으면 연결된 값을 가져올 수 있다. 존재하지 않는 새 키에 값을 대입하면 항목이 추가되고, 이미 존재하는 키에 대입하면 값이 변경된다.

```python
person = {
    'name': '홍길동',
    'age': 25,
}

# 키 'name'으로 연결된 값을 가져온다.
print(person['name'])  # 홍길동

my_dict = {
    'apple': 12,
    'items': [1, 2, 3],
}

# 없던 키에 값을 대입하므로 새 항목이 추가된다.
my_dict['banana'] = 50
print(my_dict)
# {'apple': 12, 'items': [1, 2, 3], 'banana': 50}

# 기존 키에 새 값을 대입하므로 값이 변경된다.
my_dict['apple'] = 100
print(my_dict)
# {'apple': 100, 'items': [1, 2, 3], 'banana': 50}
```

⚠️ 주의: 존재하지 않는 키를 `person['address']`처럼 조회하면 `KeyError`가 발생한다. 이후 딕셔너리 메서드를 배울 때는 키가 없을 경우 기본값을 줄 수 있는 `get()`도 다루게 된다.

### 3.11 세트: 중복과 순서가 없는 집합

세트(`set`)는 순서와 중복이 없는 가변 컬렉션이다. 같은 값이 여러 번 들어와도 하나만 남기 때문에 중복 제거에 유용하고, 수학의 집합처럼 합집합·차집합·교집합을 계산할 수 있다.

```python
# 빈 중괄호는 딕셔너리이므로 빈 세트는 set()으로 만든다.
empty_set = set()

# 중복된 1은 하나만 남는다.
my_set = {1, 1, 2, 3}

print(empty_set)  # set()
print(my_set)     # {1, 2, 3}처럼 출력되지만 순서는 보장하지 않는다.
```

세트는 순서가 없으므로 `my_set[0]` 같은 인덱싱이나 `my_set[0:2]` 같은 슬라이싱을 사용할 수 없다. 특정 값의 존재 여부는 뒤에서 배울 `in` 연산자로 확인한다.

### 3.12 세트의 집합 연산

두 데이터 그룹 사이의 공통 항목이나 차이를 찾을 때 세트의 집합 연산이 직접적인 표현이 된다.

```python
my_set_1 = {1, 2, 3}
my_set_2 = {3, 6, 9}

# 두 세트의 모든 요소를 모은다.
print(my_set_1 | my_set_2)  # {1, 2, 3, 6, 9}

# 첫 번째 세트에만 있는 요소를 남긴다.
print(my_set_1 - my_set_2)  # {1, 2}

# 두 세트에 공통으로 있는 요소만 남긴다.
print(my_set_1 & my_set_2)  # {3}
```

⚠️ 주의: 세트 출력 순서에 의존하면 안 된다. 화면에 특정 순서로 보이더라도 그 순서가 세트의 의미는 아니다.

📌 핵심: 세트는 위치보다 **유일성**과 **집합 관계**가 중요한 데이터에 사용한다.

### 3.13 None: 값이 없다는 상태

`None`은 파이썬에서 값이 없음을 나타내는 특별한 값이다. 숫자 `0`, 빈 문자열 `''`, 빈 리스트 `[]`처럼 값은 존재하지만 비어 있는 상태와 다르다. 아직 값이 정해지지 않았거나 결과가 없다는 상태를 명시할 때 사용한다.

```python
# 아직 실제 값을 정하지 않았음을 표현한다.
selected_product = None

print(selected_product)  # None
```

빈 상자와 상자가 없는 상태를 구분한다고 생각하면 쉽다. 빈 문자열은 “문자열이 있지만 내용이 없음”이고, `None`은 “현재 지정된 값이 없음”이다.

### 3.14 Boolean: 참과 거짓을 나타내는 값

불리언(`bool`)은 `True`와 `False` 두 값만 가진다. 비교나 논리 연산의 결과로 만들어지며, 조건문과 반복문이 다음 동작을 결정하는 기준이 된다.

```python
# 상태를 직접 불리언으로 저장할 수 있다.
is_active = True
is_logged_in = False

print(is_active)       # True
print(is_logged_in)    # False

# 비교식의 결과도 불리언이다.
print(10 > 5)          # True
print(10 == 5)         # False
```

파이썬에서 `bool`은 정수 타입과 밀접하게 연결되어 `True`가 `1`, `False`가 `0`처럼 산술 연산에 참여할 수 있다. 다만 상태를 표현하는 코드에서는 숫자 계산용 값과 불리언의 의미를 구분해 작성하는 편이 명확하다.

### 3.15 컬렉션의 공통 분류: 시퀀스와 가변성

컬렉션은 여러 값을 하나로 묶어 관리하는 자료형을 통칭한다. 이번 강의에서 다룬 `str`, `list`, `tuple`, `range`, `dict`, `set`이 여기에 포함된다.

| 컬렉션 | 변경 가능 | 순서 존재 | 분류와 핵심 접근 방식 |
|---|---:|---:|---|
| `str` | X | O | 시퀀스, 인덱스로 문자 접근 |
| `list` | O | O | 시퀀스, 인덱스로 요소 접근 |
| `tuple` | X | O | 시퀀스, 인덱스로 요소 접근 |
| `range` | X | O | 정수 시퀀스의 규칙 |
| `dict` | O | X | 비시퀀스, 키로 값 접근 |
| `set` | O | X | 비시퀀스, 유일성과 집합 관계 |

파이썬 3.7 이상에서 딕셔너리가 입력 순서를 보존한다는 사실과, 딕셔너리를 시퀀스로 분류하는 것은 다른 문제다. 딕셔너리는 인덱스 위치가 아니라 키를 중심으로 사용하는 비시퀀스 컬렉션이다.

가변과 불변의 구분은 생성 뒤 내용을 바꿀 수 있는지를 나타낸다.

| 구분 | 특징 | 해당 자료형 |
|---|---|---|
| 불변(`immutable`) | 생성된 객체의 내용을 변경할 수 없음 | `str`, `tuple`, `range` |
| 가변(`mutable`) | 생성된 객체의 내용을 변경할 수 있음 | `list`, `dict`, `set` |

```python
# 문자열은 불변이므로 한 글자만 바꿀 수 없다.
my_str = 'hello'
my_str[0] = 'H'
# TypeError: 'str' object does not support item assignment

# 리스트는 가변이므로 특정 요소를 바꿀 수 있다.
my_list = [1, 2, 3]
my_list[0] = 100
print(my_list)  # [100, 2, 3]
```

⚠️ 주의: “변수에 새 값을 다시 대입할 수 있다”와 “객체 자체가 가변이다”는 다르다. 문자열 변수에 새 문자열을 대입할 수는 있지만, 기존 문자열 객체의 한 글자를 직접 바꾸는 것은 불가능하다.

### 3.16 형 변환: 계산에 맞게 타입 바꾸기

형 변환(`type conversion`)은 한 데이터 타입을 다른 타입으로 바꾸는 과정이다. 입력으로 받은 `'100'`은 문자열이므로 숫자 계산을 하려면 정수 `100`으로 바꿔야 한다. 반대로 숫자를 문장에 이어 붙이려면 문자열로 바꿔야 한다.

형 변환에는 파이썬이 자동으로 처리하는 **암시적 형 변환**과 개발자가 변환 함수를 직접 호출하는 **명시적 형 변환**이 있다.

### 3.17 암시적 형 변환

암시적 형 변환은 연산 과정에서 파이썬이 자동으로 타입을 맞추는 동작이다. 주로 불리언과 숫자 타입 사이, 정수와 실수 사이에서 일어난다. 데이터 손실 가능성이 낮은 방향으로 변환한다.

```python
# 정수 3이 실수 계산에 맞춰 3.0처럼 취급되어 결과가 float가 된다.
print(3 + 5.0)       # 8.0

# bool은 숫자 맥락에서 True=1, False=0처럼 계산된다.
print(True + 3)      # 4
print(True + False)  # 1
```

파이썬이 모든 타입 조합을 자동으로 바꾸는 것은 아니다. 정수 `1`과 문자열 `'2'`를 더하면 어떤 의미인지 명확하지 않으므로 오류가 난다.

```python
print(1 + '2')
# TypeError: unsupported operand type(s) for +: 'int' and 'str'
```

⚠️ 주의: 자동 변환을 기대해 문자열과 숫자를 바로 계산하면 안 된다. 외부 입력은 문자열인 경우가 많으므로 계산 전에 타입을 확인하고 명시적으로 변환해야 한다.

### 3.18 명시적 형 변환

명시적 형 변환은 개발자가 원하는 타입의 함수를 직접 호출하는 방식이다. 변환하려는 값이 대상 타입의 규칙에 맞아야 한다.

| 함수 | 목적 | 예시 | 결과 |
|---|---|---|---|
| `int()` | 정수로 변환 | `int('123')` | `123` |
| `float()` | 실수로 변환 | `float('3.14')` | `3.14` |
| `str()` | 문자열로 변환 | `str(100)` | `'100'` |
| `list()` | 리스트로 변환 | `list('abc')` | `['a', 'b', 'c']` |
| `tuple()` | 튜플로 변환 | `tuple([1, 2])` | `(1, 2)` |
| `set()` | 세트로 변환 | `set([1, 2, 2])` | `{1, 2}` |

```python
# 정수 형식의 문자열을 정수로 바꾼다.
print(int('1'))          # 1

# 실수는 소수 부분을 버리고 정수로 바뀐다.
print(int(3.5))          # 3

# 실수 형식의 문자열을 실수로 바꾼다.
print(float('3.5'))      # 3.5

# 숫자를 문자열로 바꾼 뒤 다른 문자열과 연결한다.
print(str(1) + '등')     # 1등

# 문자열은 문자 단위의 리스트로 변환된다.
print(list('abc'))       # ['a', 'b', 'c']

# 세트로 바꾸면 중복이 제거된다.
print(set([1, 2, 2]))    # {1, 2}
```

문자열 `'3.5'`는 정수 표기 형식이 아니므로 `int('3.5')`로 바로 바꿀 수 없다.

```python
print(int('3.5'))
# ValueError: invalid literal for int() with base 10: '3.5'

# 먼저 float으로 바꾸고, 필요하다면 다시 int로 바꿀 수 있다.
print(int(float('3.5')))  # 3
```

컬렉션끼리도 변환할 수 있지만 의미가 달라질 수 있다. 문자열을 `list`나 `tuple`로 바꾸면 글자 단위로 나뉘고, 리스트나 튜플을 `set`으로 바꾸면 순서와 중복이 사라진다. 딕셔너리를 `list()`, `tuple()`, `set()`에 넣으면 기본적으로 키만 변환 대상이 된다.

```python
data = {'name': '홍길동', 'age': 25}

# 딕셔너리를 순회하는 기본 대상은 키다.
print(list(data))   # ['name', 'age']
print(tuple(data))  # ('name', 'age')
print(set(data))    # {'name', 'age'}처럼 키의 세트
```

⚠️ 주의: 형 변환 가능 여부를 표째로 외우기보다, 원본이 어떤 값을 순회하고 변환 뒤 어떤 성질이 사라지는지 확인하는 편이 안전하다. 특히 세트 변환은 순서와 중복을 보존하지 않는다.

### 3.19 산술 연산자

산술 연산자는 숫자를 계산한다. 일반적인 사칙연산 외에도 몫, 나머지, 거듭제곱을 구할 수 있다.

| 기호 | 의미 | 예시 | 결과 |
|---|---|---|---:|
| `+` | 덧셈 또는 양수 부호 | `7 + 3` | `10` |
| `-` | 뺄셈 또는 음수 부호 | `7 - 3` | `4` |
| `*` | 곱셈 | `7 * 3` | `21` |
| `/` | 나눗셈 | `7 / 3` | `2.333...` |
| `//` | 정수 나눗셈의 몫 | `7 // 3` | `2` |
| `%` | 나머지 | `7 % 3` | `1` |
| `**` | 거듭제곱 | `2 ** 3` | `8` |

```python
a = 7
b = 3

print(a + b)   # 10
print(a - b)   # 4
print(a * b)   # 21
print(a / b)   # 2.3333333333333335
print(a // b)  # 2
print(a % b)   # 1
print(a ** b)  # 343
```

`/`는 두 정수를 나누더라도 실수 결과를 반환한다. `//`는 소수점을 단순히 표시하지 않는 연산이 아니라 몫을 내림한 결과를 만든다.

### 3.20 복합 연산자

복합 연산자는 연산과 재할당을 한 번에 표현한다. `a += b`는 `a = a + b`와 같은 흐름이다.

| 기호 | 같은 의미 |
|---|---|
| `a += b` | `a = a + b` |
| `a -= b` | `a = a - b` |
| `a *= b` | `a = a * b` |
| `a /= b` | `a = a / b` |
| `a //= b` | `a = a // b` |
| `a %= b` | `a = a % b` |
| `a **= b` | `a = a ** b` |

```python
y = 10
y -= 4
print(y)  # 6

z = 7
z *= 2
print(z)  # 14

w = 15
w /= 4
print(w)  # 3.75

q = 20
q //= 3
print(q)  # 6
```

복합 연산자는 누적 합계, 남은 수량, 반복 횟수처럼 기존 값을 기준으로 갱신할 때 코드의 의도를 짧게 보여준다.

### 3.21 비교 연산자: 관계를 불리언으로 만들기

비교 연산자는 두 값의 관계가 맞는지 확인해 `True` 또는 `False`를 반환한다.

| 기호 | 의미 |
|---|---|
| `<` | 미만 |
| `<=` | 이하 |
| `>` | 초과 |
| `>=` | 이상 |
| `==` | 값이 같음 |
| `!=` | 값이 같지 않음 |
| `is` | 같은 객체임 |
| `is not` | 같은 객체가 아님 |

```python
print(3 < 5)          # True
print(5 <= 5)         # True
print(7 > 10)         # False
print(10 >= 10)       # True
print(2 == 2.0)       # True
print(2 != 2)         # False
print('HI' == 'hi')   # False
print(1 == True)      # True
```

`==`는 두 값의 동등성, 즉 내용이 논리적으로 같은지를 비교한다. 숫자 `2`와 실수 `2.0`은 타입은 다르지만 값 비교에서는 같다. 문자열 비교는 대소문자를 구분한다.

### 3.22 ==와 is: 값과 객체 정체성의 차이

`==`는 값이 같은지를 묻고, `is`는 두 변수가 메모리에서 완전히 같은 객체를 가리키는지를 묻는다. 둘 다 한국어로 “같다”라고 말할 수 있지만 질문 자체가 다르다.

```python
# 내용은 같지만 따로 만든 두 리스트다.
a = [1, 2, 3]
b = [1, 2, 3]

print(a == b)  # True: 두 리스트의 값이 같다.
print(a is b)  # False: 서로 다른 리스트 객체다.

# b가 a와 같은 객체를 가리키게 한다.
b = a
print(a is b)  # True
```

숫자나 문자열의 값을 비교할 때 `is`를 사용하면 파이썬의 내부 최적화에 따라 의도와 다른 결과가 나올 수 있다. 값 비교에는 항상 `==`를 사용한다.

```python
print(1 == True)   # True: 논리적인 값 비교
print(1 is True)   # False: 정수 1과 불리언 True는 다른 객체

print(2 == 2.0)    # True: 수치 값은 같다.
print(2 is 2.0)    # False: int 객체와 float 객체는 다르다.
```

`is`는 대표적으로 싱글턴 객체인 `None`을 비교할 때 사용한다. 싱글턴은 프로그램에서 하나의 객체를 공유하도록 만든 특별한 객체다.

```python
result = None

# None 여부는 is 또는 is not으로 확인하는 것이 권장된다.
if result is None:
    print('아직 결과가 없습니다.')

if result is not None:
    print('결과가 준비되었습니다.')
```

⚠️ 주의: `if x == None:`도 동작할 수 있지만 권장 표기는 `if x is None:`이다. 반대로 숫자, 문자열, 리스트의 내용 비교에 `is`를 사용하지 않는다.

📌 핵심: **값 비교는 `==`, `None` 같은 객체의 정체성 비교는 `is`**를 사용한다.

### 3.23 논리 연산자: 여러 조건 조합하기

논리 연산자는 여러 조건을 조합하거나 결과를 뒤집는다. 할인 적용 조건처럼 “회원이면서 금액 기준을 넘었는가”를 표현할 때 필요하다.

| 연산자 | 의미 |
|---|---|
| `and` | 두 피연산자가 모두 참일 때 참 |
| `or` | 둘 중 하나라도 참이면 참 |
| `not` | 한 피연산자의 참·거짓을 반대로 바꿈 |

```python
print(True and False)  # False
print(True or False)   # True
print(not True)        # False
print(not 0)           # True

num = 15

# 15는 10보다 크지만 짝수가 아니므로 전체 결과는 False다.
result = (num > 10) and (num % 2 == 0)
print(result)  # False

name = 'Alice'
age = 25

# 이름 조건이 참이므로 나이 조건이 거짓이어도 전체 결과는 True다.
result = (name == 'Alice') or (age == 30)
print(result)  # True
```

괄호는 비교식의 경계를 분명히 보여 준다. 없어도 우선순위상 같은 결과가 나올 수 있지만, 처음에는 각 조건을 괄호로 묶으면 읽고 디버깅하기 쉽다.

### 3.24 참 같은 값과 거짓 같은 값

파이썬은 `True`, `False` 외의 값도 조건 자리에서 참 또는 거짓으로 평가한다. 이를 이해해야 단축 평가의 반환값을 예측할 수 있다.

대표적으로 다음 값은 거짓으로 취급된다.

- `False`
- 숫자 `0`, `0.0`
- 빈 문자열 `''`
- 빈 리스트 `[]`, 빈 튜플 `()`, 빈 딕셔너리 `{}`, 빈 세트 `set()`
- `None`

그 밖의 대부분의 값은 참으로 취급된다. 예를 들어 `1`, `-10`, `'hello'`, `[1, 2]`는 모두 참 같은 값이다.

```python
print(bool(0))        # False
print(bool(''))       # False
print(bool([]))       # False
print(bool(None))     # False

print(bool(1))        # True
print(bool(-10))      # True
print(bool('hello'))  # True
print(bool([1, 2]))   # True
```

⚠️ 주의: 문자열 `'False'`와 `'0'`은 내용이 있는 문자열이므로 참이다. 글자의 의미가 아니라 비어 있는지를 기준으로 평가한다.

### 3.25 단축 평가: 결과가 정해지면 멈추기

단축 평가는 논리 연산에서 결과가 이미 결정되면 나머지 피연산자를 평가하지 않는 동작이다. 불필요한 계산을 줄이고, 뒤쪽 표현식을 실행하면 생길 오류를 피하는 데도 사용된다.

`and`는 왼쪽부터 보다가 처음 만난 거짓 같은 값을 반환한다. 모두 참이면 마지막 값을 반환한다. `or`는 처음 만난 참 같은 값을 반환하고, 모두 거짓이면 마지막 값을 반환한다.

| 연산 | 평가 방식 | 반환값 |
|---|---|---|
| `A and B` | `A`가 거짓이면 `B`를 평가하지 않음 | 첫 거짓 값, 모두 참이면 마지막 값 |
| `A or B` | `A`가 참이면 `B`를 평가하지 않음 | 첫 참 값, 모두 거짓이면 마지막 값 |

강의의 준비물 예시로 동작을 확인해 보자.

```python
# 두 값이 모두 참 같은 값이므로 마지막 값이 반환된다.
item1 = '지도'
item2 = '나침반'
result = item1 and item2
print(f'최종적으로 챙긴 물건: {result}')
# 최종적으로 챙긴 물건: 나침반

# item2가 빈 문자열이므로 처음 만난 거짓 값인 ''가 반환된다.
item1 = '지도'
item2 = ''
result = item1 and item2
print(f'최종적으로 챙긴 물건: "{result}"')
# 최종적으로 챙긴 물건: ""

# item1이 이미 거짓이므로 item2까지 평가하지 않고 ''를 반환한다.
item1 = ''
item2 = '나침반'
result = item1 and item2
print(f'최종적으로 챙긴 물건: "{result}"')
# 최종적으로 챙긴 물건: ""
```

논리 연산자가 항상 `True`나 `False`만 반환하지 않는다는 점이 중요하다. 위 코드에서 결과는 문자열 `'나침반'` 또는 빈 문자열 `''`이다.

단축 평가로 오류를 막는 흐름도 확인할 수 있다.

```python
numbers = []

# numbers가 비어 있으면 거짓이므로 numbers[0]은 평가하지 않는다.
has_positive_first = numbers and numbers[0] > 0
print(has_positive_first)  # []
```

⚠️ 주의: 단축 평가 결과를 반드시 불리언이라고 가정하면 안 된다. 정확한 `True`나 `False`가 필요하면 `bool()`로 변환하거나 비교식을 사용한다.

### 3.26 멤버십 연산자: 포함 여부 확인하기

멤버십 연산자 `in`과 `not in`은 특정 값이 시퀀스나 컬렉션에 포함되어 있는지 확인하고 불리언을 반환한다. 장바구니에 상품이 있는지 검사할 때 직접 사용할 수 있다.

```python
word = 'hello'
numbers = [1, 2, 3, 4, 5]

print('h' in word)          # True
print('z' in word)          # False
print(4 not in numbers)     # False
print(6 not in numbers)     # True
```

문자열에서는 부분 문자열의 포함 여부를 검사하고, 리스트·튜플·세트에서는 요소의 포함 여부를 검사한다. 딕셔너리에 `in`을 사용하면 기본적으로 **키**의 존재 여부를 검사한다.

```python
product = {'name': 'keyboard', 'price': 50000}

print('name' in product)       # True
print('keyboard' in product)   # False: 값이 아니라 키를 검사한다.
```

⚠️ 주의: 딕셔너리의 값에 포함되어 있는지 확인하려면 이후 배우는 `values()`를 통해 값의 모음을 대상으로 검사해야 한다. 기본 멤버십 검사는 키를 본다.

### 3.27 시퀀스형 연산자: 연결과 반복

문자열, 리스트, 튜플 같은 시퀀스에서 `+`는 두 시퀀스를 연결하고, `*`는 시퀀스를 정해진 횟수만큼 반복한다. 숫자 계산에서 사용한 기호와 같지만 피연산자 타입에 따라 의미가 달라진다.

```python
# 두 문자열을 연결한다.
print('Gildong' + ' Hong')       # Gildong Hong

# 문자열을 5번 반복한다.
print('hi' * 5)                  # hihihihihi

# 두 리스트의 요소를 순서대로 연결해 새 리스트를 만든다.
print([1, 2] + ['a', 'b'])       # [1, 2, 'a', 'b']

# 리스트의 요소 순서를 두 번 반복해 새 리스트를 만든다.
print([1, 2] * 2)                # [1, 2, 1, 2]

# 튜플도 같은 방식으로 연결할 수 있다.
print((1, 2) + (3, 4))           # (1, 2, 3, 4)
```

⚠️ 주의: 시퀀스 연결은 호환되는 같은 종류끼리 하는 것이 기본이다. 리스트와 튜플을 `+`로 바로 연결하면 `TypeError`가 발생한다. 필요한 경우 먼저 같은 타입으로 변환한다.

### 3.28 연산자 우선순위

한 표현식에 연산자가 여러 개 있으면 우선순위가 높은 연산부터 평가한다. 강의에서 다룬 연산자의 큰 순서는 다음과 같다.

| 높음 → 낮음 | 연산자 | 의미 |
|---:|---|---|
| 1 | `()` | 그룹 묶기 |
| 2 | `[]` | 인덱싱, 슬라이싱 |
| 3 | `**` | 거듭제곱 |
| 4 | `+x`, `-x` | 단항 양수·음수 |
| 5 | `*`, `/`, `//`, `%` | 곱셈 계열 산술 연산 |
| 6 | `+`, `-` | 덧셈·뺄셈 |
| 7 | `<`, `<=`, `>`, `>=`, `==`, `!=` | 값 비교 |
| 8 | `is`, `is not` | 객체 비교 |
| 9 | `in`, `not in` | 멤버십 검사 |
| 10 | `not` | 논리 부정 |
| 11 | `and` | 논리 AND |
| 12 | `or` | 논리 OR |

```python
# 곱셈이 덧셈보다 먼저 계산된다.
print(2 + 3 * 4)       # 14

# 괄호를 사용하면 덧셈을 먼저 계산하도록 명시할 수 있다.
print((2 + 3) * 4)     # 20

# 비교 결과를 논리 연산으로 조합한다.
age = 25
print(age >= 20 and age < 30)  # True
```

우선순위를 모두 암기하는 것보다, 의도한 평가 단위를 괄호로 명확히 나타내는 습관이 더 실용적이다.

⚠️ 주의: 괄호가 지나치게 많으면 오히려 읽기 어려울 수 있다. 산술 계산의 핵심 순서나 여러 비교 조건의 경계를 드러내는 데 사용한다.

### 3.29 Trailing Comma: 마지막 요소 뒤의 쉼표

후행 쉼표(`trailing comma`)는 컬렉션이나 함수 인자 목록의 마지막 요소 뒤에 붙이는 쉼표다. 일반적으로 선택 사항이지만, 요소 하나짜리 튜플을 만들 때는 필수다.

```python
x = 1      # 정수
x = (1)    # 정수

x = 1,     # 튜플
x = (1,)   # 튜플
```

여러 줄로 항목을 작성할 때는 각 요소를 별도 줄에 두고, 마지막 요소에도 쉼표를 붙이며, 닫는 괄호를 새 줄에 배치하면 구조가 선명하다.

```python
items = [
    'item1',
    'item2',
    'item3',
]

config = {
    'host': 'localhost',
    'port': 8080,
    'debug': True,
}

my_func(
    'value1',
    'value2',
)
```

한 줄짜리 목록에서는 마지막 쉼표가 없어도 읽기 쉽다.

```python
items = ['item1', 'item2']
my_func('value1', 'value2')
```

후행 쉼표를 사용하면 새 항목을 추가하거나 삭제할 때 수정되는 줄이 줄어든다. 각 줄이 같은 형태를 가지므로 코드 리뷰에서 변경점도 분명해지고, 항목 사이의 쉼표를 빠뜨리는 실수도 줄어든다.

⚠️ 주의: 한 줄 목록에 무조건 후행 쉼표를 붙이는 것은 강의에서 권장한 형식이 아니다. 여러 줄 구조에서 일관되게 사용하고, 단일 요소 튜플에서는 반드시 사용한다.

## 4. 적용 관점에서 다시 보기

자료형을 고를 때는 먼저 데이터가 어떤 성질을 가져야 하는지 묻는다. 상품을 담은 순서가 중요하고 수량이 계속 바뀐다면 리스트가 적합하다. 상품 이름으로 가격을 찾고 싶다면 딕셔너리, 선택된 카테고리의 중복을 없애고 싶다면 세트를 떠올린다. 값이 바뀌면 안 되는 좌표나 묶음은 튜플, 반복 횟수는 `range`로 표현한다.

장바구니를 구현하는 흐름은 다음과 같이 잡을 수 있다.

1. 상품들의 순서 있는 목록은 리스트에 저장한다.
2. 상품 이름과 가격처럼 의미 있는 연결은 딕셔너리에 저장한다.
3. `in`으로 상품이나 키가 존재하는지 먼저 확인한다.
4. 수량과 가격은 산술 연산자로 계산한다.
5. 회원 여부와 최소 주문 금액 같은 조건은 비교식과 `and`, `or`로 조합한다.
6. 값이 아직 정해지지 않았다면 빈 문자열이나 `0`과 혼동하지 말고 `None`으로 나타낸다.

외부에서 입력받은 값은 타입부터 확인해야 한다. 화면에서 받은 수량 `'3'`은 문자열이므로 바로 가격과 곱할 수 없다. `int()`로 변환할 수 있는 형식인지 확인한 다음 계산에 사용한다. 세트로 중복을 제거하거나 리스트로 다시 변환할 때는 순서가 사라질 수 있다는 점도 함께 고려한다.

조건이 길어지면 우선순위에 기대기보다 비교 단위별로 괄호를 사용한다. 특히 `==`와 `is`를 구분해 값 비교에는 `==`, `None` 검사에는 `is None`을 적용한다. 딕셔너리 멤버십이 값을 찾는 것이 아니라 키를 찾는다는 점도 자주 확인해야 한다.

단축 평가는 왼쪽 조건이 뒤쪽 연산의 안전을 보장할 때 유용하다. 다만 결과가 `True`나 `False`가 아니라 실제 피연산자일 수 있으므로, 반환값을 이후 코드가 어떤 타입으로 기대하는지 확인한다.

마지막으로 여러 줄 리스트, 딕셔너리, 함수 호출을 작성할 때 후행 쉼표를 사용하면 항목 추가와 삭제가 단순해진다. 이는 실행 결과를 바꾸는 핵심 문법이라기보다 유지보수하기 좋은 코드 형식을 만드는 습관이다. 단, 단일 요소 튜플에서는 형식이 아니라 타입을 결정하는 필수 쉼표다.

---

## 5. 배운 점 / 확장 포인트

### 5.1 이번 강의 이전에 몰랐던 것 또는 새로 이해된 것

여러 값을 저장하는 자료형은 모양만 다른 것이 아니라 순서, 중복, 변경 가능성, 접근 방식에 따라 역할이 나뉜다는 점을 이해했다. 또한 `and`와 `or`는 무조건 불리언을 반환하는 연산자가 아니라, 평가를 멈춘 위치의 실제 값을 반환할 수 있다는 점이 새롭다.

### 5.2 앞으로 이어지는 연결점

컬렉션과 연산자는 조건문, 반복문, 함수에서 계속 사용된다. 특히 `range`는 `for` 반복문으로, 딕셔너리와 세트는 메서드와 순회로, `None`과 논리 연산은 분기 처리로 자연스럽게 이어진다.

### 5.3 더 파볼 만한 주제

리스트·딕셔너리·세트의 추가 및 삭제 메서드, 얕은 복사와 깊은 복사, 해시 가능성과 딕셔너리 키의 조건, 컴프리헨션, 단축 평가를 활용한 기본값 처리 등을 더 살펴볼 수 있다.

## 6. 요약 정리

📌 핵심

- 리스트는 순서가 있고 변경 가능하며, 인덱싱과 슬라이싱을 사용할 수 있다.
- 튜플은 순서가 있지만 변경할 수 없고, 단일 요소 튜플에는 쉼표가 필요하다.
- `range`는 정수 목록 전체가 아니라 시작·종료·간격의 규칙을 표현하며 `stop`을 포함하지 않는다.
- 딕셔너리는 키로 값에 접근하고, 세트는 중복 없는 집합 관계를 표현한다.
- `None`은 빈 값과 구별되는 “값 없음”의 상태이고, 불리언은 조건 판단의 결과다.
- `str`, `tuple`, `range`는 불변이고 `list`, `dict`, `set`은 가변이다.
- 암시적 형 변환은 제한된 안전한 범위에서 자동으로 일어나며, 대부분의 타입 변경은 변환 함수를 명시적으로 호출한다.
- 값 비교에는 `==`, 동일 객체 또는 `None` 비교에는 `is`를 사용한다.
- `and`는 첫 거짓 값을, `or`는 첫 참 값을 만나면 평가를 멈추며 실제 피연산자를 반환할 수 있다.
- `in`은 포함 여부를 검사하고, 딕셔너리에서는 기본적으로 키를 검사한다.
- 시퀀스의 `+`는 연결, `*`는 반복을 뜻한다.
- 여러 연산이 섞이면 우선순위를 확인하고, 필요한 계산 단위를 괄호로 분명하게 표현한다.
- 여러 줄 컬렉션에는 후행 쉼표가 유지보수에 유리하며, 단일 요소 튜플에서는 필수다.

🧠 기억할 것

자료형은 문법 모양이 아니라 데이터의 성질로 선택한다. “순서가 필요한가, 바뀌어야 하는가, 중복을 허용하는가, 어떤 방식으로 찾을 것인가”를 먼저 판단하면 올바른 컬렉션을 고르기 쉽다.
