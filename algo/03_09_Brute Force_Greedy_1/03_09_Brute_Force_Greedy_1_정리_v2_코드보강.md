## 1. 들어가며

이 글에서는 **재귀호출을 이용해 반복 구조를 일반화하는 방법**과, 그 아이디어가 **완전탐색 문제 해결**로 어떻게 이어지는지를 정리한다.

처음에는 2중 for문처럼 단순한 반복 예시로 시작하지만, 강의가 진행될수록 핵심은 분명해진다.  
**“반복문으로는 고정된 깊이만 쉽게 표현할 수 있지만, 재귀는 깊이가 바뀌는 탐색 구조를 자연스럽게 만들 수 있다.”**

이 차이를 이해하면 순열, 중복순열, 주사위 합 문제처럼 **모든 경우를 하나씩 만들어 보는 문제**를 훨씬 체계적으로 다룰 수 있다.  
즉, 이번 강의는 재귀 문법을 익히는 시간이 아니라, **탐색 문제를 바라보는 사고방식**을 만드는 시간이라고 볼 수 있다.

## 2. 핵심 개념 정리

이 섹션에서는 강의 전체를 이해하는 데 필요한 핵심 개념을 먼저 정리한다.

### 2-1. 반복과 재귀는 비슷하지만, 표현력이 다르다

반복(`for`, `while`)과 재귀(`함수가 자기 자신을 다시 호출`)는 비슷한 작업을 수행할 수 있다.  
하지만 둘의 강점은 다르다.

| 구분 | 반복 | 재귀 |
|---|---|---|
| 기본 방식 | 같은 코드를 여러 번 실행 | 더 작은 같은 문제를 다시 호출 |
| 강점 | 단순 반복 처리에 강함 | 트리 구조, 경우의 수 생성에 강함 |
| 익숙한 예 | 2중 for문, 3중 for문 | 순열, 부분집합, DFS, 백트래킹 |
| 주의점 | 중첩 깊이가 고정돼야 편함 | **기저조건**이 없으면 무한호출 위험 |

📌 **핵심**  
재귀는 “어렵게 반복을 쓰는 문법”이 아니라,  
**반복 깊이가 유동적인 문제를 더 자연스럽게 표현하는 도구**다.

### 2-2. 재귀에서 가장 중요한 것은 기저조건이다

재귀는 자기 자신을 계속 호출하므로, 반드시 멈추는 조건이 있어야 한다.  
이 멈추는 조건을 **기저조건(base case)** 이라고 한다.

예를 들어 숫자 0부터 10까지 출력하는 재귀 함수라면,  
`num > 10`일 때 종료해야 무한호출이 발생하지 않는다.

⚠️ **주의**  
재귀를 처음 배울 때 가장 많이 하는 실수는 두 가지다.

1. **기저조건을 빼먹는 것**
2. **호출 전/후 상태 복구를 하지 않는 것**

특히 `path`를 사용하는 탐색 문제에서는 `append()` 후 반드시 `pop()`이 따라와야 한다.

### 2-3. 재귀를 이해하려면 함수 호출 구조를 알아야 한다

강의에서는 재귀를 본격적으로 다루기 전에, 일반 함수 호출의 특징부터 짚는다.

#### 특징 1) 정수 같은 기본값은 “값”이 복사되어 전달된다

함수에 `int` 값을 넘기면, 원본 변수 자체가 넘어가는 것이 아니라 **값이 복사된 새로운 지역 변수**가 사용된다.

![함수 호출 시 값 복사](img_01_value_copy.png)

이 그림은 `main`의 `x`와 함수 내부의 `x`가 같은 이름이어도 **서로 다른 변수**라는 점을 보여준다.  
그래서 함수 안에서 `x += 1`을 해도 바깥의 `x`는 그대로 유지된다.

#### 특징 2) 함수가 끝나면 “호출한 자리”로 돌아온다

함수가 끝나면 무조건 main으로 돌아가는 것이 아니라,  
**그 함수를 호출했던 정확한 위치**로 돌아간다.

![호출한 자리로 복귀하는 구조](img_02_return_to_callsite.png)

이 감각은 재귀를 이해할 때 매우 중요하다.  
재귀는 사실 “새로운 함수 호출이 계속 쌓였다가, 끝에서부터 되돌아오는 구조”이기 때문이다.

🧠 **기억할 것**  
재귀는 위에서 아래로만 내려가는 과정이 아니라,  
**내려가고 돌아오고를 반복하는 흐름**까지 포함해서 이해해야 한다.

### 2-4. Level, Branch, path는 재귀 탐색의 핵심 언어다

강의 전체를 관통하는 핵심 표현은 아래 세 가지다.

- **Level**: 지금 몇 번째 선택까지 진행했는가
- **Branch**: 현재 단계에서 몇 개의 선택지가 있는가
- **path**: 지금까지 무엇을 선택해 왔는가

예를 들어 주사위를 3번 던진다면,

- Level = 3
- Branch = 6
- path = 지금까지 선택한 주사위 눈

이렇게 볼 수 있다.

이 관점을 익히면 문제를 보면 바로 이렇게 바꿔 말할 수 있다.

> “아, 이 문제는 Level이 몇이고, 각 Level마다 Branch가 몇 개인지부터 정리하면 되겠구나.”

## 3. 본문 정리

이 섹션에서는 강의 흐름에 맞춰 개념이 어떻게 확장되는지 정리한다.

### 3-1. 2중 for문에서 N중 for문으로: 왜 재귀가 필요한가

가장 단순한 예시는 `1, 2, 3`으로 만들 수 있는 두 자릿수 출력이다.

```python
# 바깥쪽 자리(a)는 1부터 3까지 반복한다.
for a in range(1, 4):
    # 안쪽 자리(b)도 1부터 3까지 반복한다.
    for b in range(1, 4):
        # 현재 두 자릿수 조합을 출력한다.
        print(a, b)
```

이 코드는 2중 for문이라 간단하다.  
하지만 자릿수가 3, 4, 5처럼 늘어나면 어떻게 될까?

- N이 2면 2중 for문
- N이 3이면 3중 for문
- N이 9면 9중 for문

이 방식은 너무 비효율적이다.  
바로 이 지점에서 재귀가 등장한다.

### 3-2. 재귀는 N중 for문을 일반화한다

재귀를 쓰면 “현재 자리에서 1, 2, 3 중 하나를 고르고 다음 자리로 이동”이라는 패턴을 공통으로 표현할 수 있다.

```python
# 지금까지 선택한 숫자를 저장할 리스트
path = []
# 만들고 싶은 자릿수
N = 3

# lev는 현재 몇 번째 자리까지 채웠는지 뜻한다.
def run(lev):
    # 기저조건: N개를 모두 골랐다면 현재 경로를 출력하고 종료
    if lev == N:
        print(path)
        return

    # 현재 자리에 1, 2, 3 중 하나를 넣어 본다.
    for i in range(1, 4):
        # 현재 선택을 path에 기록한다.
        path.append(i)
        # 다음 자리로 내려간다.
        run(lev + 1)
        # 돌아오면 방금 선택을 취소한다.
        path.pop()

# 0번째 자리부터 시작한다.
run(0)
```

이 코드의 핵심은 단순하다.

1. 현재 자리에 숫자를 하나 넣는다.
2. 다음 자리로 재귀호출한다.
3. 돌아오면 방금 넣은 숫자를 빼고 다른 선택을 시도한다.

즉, **선택 → 내려감 → 복구**가 재귀 탐색의 기본 패턴이다.

💡 **포인트**  
여기서 `path.pop()`은 선택을 “취소”하는 동작이다.  
이 한 줄이 있어야 이전 상태로 돌아가 다른 경우를 이어서 만들 수 있다.

재귀는 코드를 위에서 아래로 읽는 것이 아니라, **호출 트리 전체를 머릿속에 그릴 수 있어야 한다**는 점이다.

그래서 완전탐색 문제는 자연스럽게 **트리 탐색 문제처럼 해석**할 수 있다.

### 3-4. 중복순열: 같은 숫자를 여러 번 써도 되는 경우

강의에서는 카드 `0, 1, 2` 중에서 2장을 뽑는 예시로 **중복순열**을 설명한다.

중복순열은 다음과 같은 특징을 가진다.

- 순서를 고려한다.
- 같은 원소를 여러 번 사용할 수 있다.
- 따라서 `[0, 0]`, `[1, 1]`, `[2, 2]`도 허용된다.

![중복순열 생성 구조](img_10_repeated_permutation.png)

핵심 아이디어는 간단하다.

1. 재귀호출을 할 때마다 선택한 값을 `path`에 남긴다.
2. 마지막 Level에 도달하면 `path`를 출력한다.

즉, **path는 지금까지 선택한 흔적**이다.

### 3-5. 순열: 중복을 허용하지 않는 경우

이제 중복순열 코드에 “이미 쓴 숫자는 다시 쓰지 못하게 하는 장치”를 추가하면 순열이 된다.

그 장치가 바로 `used` 또는 `visited` 배열이다.

![순열 도입 그림](img_09_permutation_intro.png)

![used 배열로 중복 제거](img_11_used_array.png)

원리는 다음과 같다.

- 어떤 숫자를 고르기 전, 이미 사용했는지 확인한다.
- 사용하지 않았다면 `used[i] = True`로 표시한다.
- 재귀가 끝나고 돌아오면 `used[i] = False`로 원상복구한다.

이 패턴은 이후 DFS, 백트래킹, 그래프 탐색에서도 계속 등장한다.

📌 **핵심**  
중복순열 + 사용 여부 체크 = 순열

### 3-6. 완전탐색은 “가능한 모든 경우를 다 해보는 것”이다

완전탐색(Brute Force)은 가능한 경우를 모두 시도해서 답을 찾는 방법이다.

겉보기에는 단순해 보이지만, 실전에서는 매우 중요하다.

- 아이디어 검증용으로 좋다.
- 작은 입력에서는 정답을 확실하게 찾을 수 있다.
- 가지치기까지 붙이면 생각보다 강력하다.

강의의 예시도 모두 같은 흐름으로 풀린다.

- 주사위 3개를 던져 합이 10 이하인 경우 세기
- 5장의 카드 중 같은 문자가 3장 연속 나오는 경우 세기
- 6장의 카드가 Baby-gin인지 검사하기

결국 질문은 항상 비슷하다.

> “모든 경우를 어떻게 만들 것인가?”  
> “만든 경우가 조건을 만족하는지 어떻게 검사할 것인가?”

## 4. 적용 / 예시 / 코드 해설

이 섹션에서는 **강의에 실제로 등장한 코드를 최대한 살리면서**, 줄마다 주석을 붙여 흐름을 따라갈 수 있게 정리한다.

### 4-1. 2중 for문으로 두 자릿수 만들기

이 코드는 재귀로 넘어가기 전에, 반복문만으로 가능한 가장 단순한 형태를 보여준다.

```python
# 첫 번째 자리에 들어갈 숫자를 1, 2, 3 중에서 하나씩 고른다.
for a in range(1, 4):
    # 두 번째 자리에 들어갈 숫자도 1, 2, 3 중에서 하나씩 고른다.
    for b in range(1, 4):
        # 현재 선택된 두 자리 숫자 조합을 출력한다.
        print(a, b)
```

#### 코드 흐름 해설

- 바깥 `for`문은 첫 번째 자리 선택이다.
- 안쪽 `for`문은 두 번째 자리 선택이다.
- 즉, 이 코드는 **Level이 2인 고정 구조**다.

#### 자주 하는 실수 / 디버깅 포인트

- 자리 수가 늘어날 때마다 반복문을 더 중첩해야 하므로 확장성이 떨어진다.
- 그래서 N이 바뀌는 문제에서는 재귀가 더 자연스럽다.

### 4-2. 재귀로 N자리 수 만들기

반복 구조를 일반화한 가장 대표적인 코드다.

```python
# 지금까지 선택한 숫자를 저장하는 리스트다.
path = []
# 만들고 싶은 전체 자리 수다.
N = 3

# lev는 현재 몇 번째 자리까지 채웠는지 의미한다.
def run(lev):
    # 기저조건: N자리를 모두 채웠다면 현재 경로를 출력한다.
    if lev == N:
        print(path)
        return

    # 현재 자리에는 1, 2, 3을 모두 넣어볼 수 있다.
    for i in range(1, 4):
        # 현재 숫자를 path에 추가해 선택을 기록한다.
        path.append(i)
        # 다음 자리로 이동한다.
        run(lev + 1)
        # 다음 경우를 만들기 위해 방금 선택한 숫자를 제거한다.
        path.pop()

# 아직 아무 자리도 채우지 않은 0레벨부터 시작한다.
run(0)
```

#### 코드 흐름 해설

- `lev`는 현재 깊이다.
- `path`는 지금까지 만들어진 숫자다.
- `lev == N`이면 완성된 숫자 하나를 얻은 것이다.

#### 자주 하는 실수 / 디버깅 포인트

- `path.pop()`을 빼먹으면 이전 선택이 남아 결과가 꼬인다.
- `lev == N`보다 늦게 종료하면 불필요한 호출이 더 생긴다.

### 4-3. 0부터 10까지 출력하는 재귀 기본형

재귀의 기본 모양을 가장 직관적으로 보여주는 예시다.

```python
# 재귀함수는 자기 자신을 다시 호출하는 함수다.
# 이때 반드시 끝나는 조건이 있어야 한다.
# 여기서는 0부터 시작해서 10까지 출력한다.

def recur(num):
    # 10보다 커졌다면 더 이상 출력하지 않고 종료한다.
    if num > 10:
        return
    # 현재 숫자를 출력한다.
    print(num, end=' ')
    # 다음 숫자를 출력하기 위해 num + 1로 다시 호출한다.
    recur(num + 1)

# 시작값 0부터 재귀를 시작한다.
recur(0)
```

#### 코드 흐름 해설

- `recur(0)`에서 시작한다.
- 한 번 호출될 때마다 `num`이 1씩 증가한다.
- `num > 10`이 되면 멈춘다.

#### 자주 하는 실수 / 디버깅 포인트

- 기저조건이 없으면 무한 재귀가 된다.
- `print` 위치를 바꾸면 출력 순서가 달라질 수 있다.

### 4-4. 값 복사: 함수에 int를 넘기면 어떻게 될까

강의에서 재귀 전에 먼저 짚고 간 “함수 호출의 기본” 예시다.

```python
# x를 매개변수로 받는 함수를 만든다.
def KFC(x):
    # 함수 안으로 들어온 x 값을 먼저 출력한다.
    print(x)
    # 함수 안의 지역변수 x를 1 증가시킨다.
    x += 1
    # 증가한 뒤의 x를 다시 출력한다.
    print(x)

# 바깥쪽 x를 3으로 둔다.
x = 3
# x + 1 값을 넘겨 함수에 전달한다.
KFC(x + 1)
# 함수 호출이 끝난 뒤 바깥쪽 x를 출력한다.
print(x)
```

#### 코드 흐름 해설

- 함수 안의 `x`와 바깥 `x`는 같은 이름이지만 다른 변수다.
- 그래서 함수 안에서 `x += 1`을 해도 바깥 `x`는 변하지 않는다.

#### 자주 하는 실수 / 디버깅 포인트

- “함수 안에서 바꿨으니 원래 변수도 바뀌겠지?”라고 생각하면 헷갈리기 쉽다.
- 정수 같은 기본형은 값이 복사되어 전달된다는 감각을 먼저 잡는 것이 중요하다.

### 4-5. 함수는 호출한 자리로 돌아온다

이 코드는 함수가 끝나면 어디로 복귀하는지를 보여준다.

```python
# BBQ 함수는 값을 받아서 10을 더한 뒤 출력한다.
def BBQ(x):
    # 전달받은 x에 10을 더한다.
    x += 10
    # 계산 결과를 출력한다.
    print(x)

# KFC 함수는 BBQ를 호출한 뒤 다시 자기 흐름을 이어간다.
def KFC(x):
    # 현재 x를 먼저 출력한다.
    print(x)
    # x에 3을 더한다.
    x += 3
    # x + 2를 넘겨 BBQ를 호출한다.
    BBQ(x + 2)
    # BBQ가 끝나고 돌아오면 현재 KFC의 x를 다시 출력한다.
    print(x)

# 바깥쪽 x를 3으로 둔다.
x = 3
# x + 1 값을 넣어 KFC를 호출한다.
KFC(x + 1)
# 모든 함수 호출이 끝난 뒤 바깥쪽 x를 출력한다.
print(x)
```

#### 코드 흐름 해설

- `KFC` 안에서 `BBQ`를 호출하면, `BBQ`가 끝난 뒤 다시 `KFC` 내부의 다음 줄로 돌아온다.
- 이 원리가 재귀에서도 똑같이 적용된다.

#### 자주 하는 실수 / 디버깅 포인트

- 함수가 끝나면 무조건 `main`으로 바로 돌아간다고 생각하면 안 된다.
- **정확히 호출했던 줄 다음으로 돌아온다**는 점이 핵심이다.

### 4-6. 재귀호출 개수에 따라 트리가 달라진다

같은 함수라도 자기 자신을 몇 번 호출하느냐에 따라 호출 트리 구조가 완전히 달라진다.

#### (1) 재귀호출이 2개인 경우

```python
# x를 받아 재귀적으로 두 번씩 내려가는 함수다.
def KFC(x):
    # x가 2가 되면 더 내려가지 않고 종료한다.
    if x == 2:
        return
    
    # 첫 번째 가지로 내려간다.
    KFC(x + 1)
    # 두 번째 가지로도 내려간다.
    KFC(x + 1)
    # 두 재귀 호출이 모두 끝난 뒤 현재 x를 출력한다.
    print(x)

# 시작 깊이 0에서 실행한다.
KFC(0)
```

#### (2) 재귀호출이 3개인 경우

```python
# x를 받아 재귀적으로 세 번씩 내려가는 함수다.
def KFC(x):
    # x가 2가 되면 종료한다.
    if x == 2:
        return
    
    # 첫 번째 재귀 호출
    KFC(x + 1)
    # 두 번째 재귀 호출
    KFC(x + 1)
    # 세 번째 재귀 호출
    KFC(x + 1)

    # 세 갈래 탐색이 모두 끝난 뒤 현재 x를 출력한다.
    print(x)

# 시작 깊이 0에서 실행한다.
KFC(0)
```

#### (3) for문으로 재귀호출 여러 개 표현하기

```python
# x를 현재 깊이라고 보고 동작하는 함수다.
def KFC(x):
    # x가 3이 되면 더 내려가지 않는다.
    if x == 3:
        return
    
    # 현재 단계에서 1, 2, 3 세 갈래로 내려간다.
    for i in range(1, 4):
        # 실제로는 i 값을 쓰지 않고, 갈래 수만큼 재귀호출한다.
        KFC(x + 1)

# 원래 노트에 적힌 출력 코드도 그대로 둔다.
print(0)
```

#### 코드 흐름 해설

- 재귀호출이 2개면 각 정점에서 두 갈래다.
- 재귀호출이 3개면 각 정점에서 세 갈래다.
- 이 구조를 일반화하면 **Level과 Branch** 개념으로 정리할 수 있다.

#### 자주 하는 실수 / 디버깅 포인트

- 재귀 호출이 끝난 뒤 `print(x)`가 실행된다는 점을 놓치면 출력 순서를 틀리기 쉽다.
- `print`가 재귀 호출 전인지 후인지에 따라 전위/후위처럼 결과가 달라진다.

### 4-7. 중복순열: 0, 1, 2 중에서 2개 고르기

강의에 나온 중복순열 코드를 원래 흐름대로 최대한 유지한 버전이다.

```python
# 중복 순열
# [0, 1, 2] 3개의 카드가 존재하고, 그중 2개를 뽑는 모든 경우를 만든다.

# 현재까지 고른 카드를 저장할 경로 리스트다.
path = []

# cnt는 현재 몇 장 골랐는지 나타낸다.
def recur(cnt):
    # 2장을 모두 골랐다면 현재 경로를 출력하고 종료한다.
    if cnt == 2:
        print(path)
        return
    
    # 0을 선택하는 경우다.
    path.append(0)
    # 한 장 더 고르기 위해 다음 단계로 내려간다.
    recur(cnt + 1)
    # 다음 선택을 위해 방금 고른 0을 되돌린다.
    path.pop()

    # 1을 선택하는 경우다.
    path.append(1)
    # 다음 단계로 내려간다.
    recur(cnt + 1)
    # 1 선택을 취소한다.
    path.pop()

    # 2를 선택하는 경우다.
    path.append(2)
    # 다음 단계로 내려간다.
    recur(cnt + 1)
    # 2 선택을 취소한다.
    path.pop()

# 0장 고른 상태에서 시작한다.
recur(0)
```

같은 내용을 `for`문으로 줄이면 아래처럼 쓸 수 있다.

```python
# 현재까지 고른 카드를 저장할 경로 리스트다.
path = []

# cnt는 현재 몇 장 골랐는지 의미한다.
def recur(cnt):
    # 2장을 모두 골랐다면 출력한다.
    if cnt == 2:
        print(path)
        return
    
    # 0, 1, 2를 반복해서 하나씩 선택한다.
    for i in range(3):
        # 현재 숫자를 경로에 추가한다.
        path.append(i)
        # 다음 장을 고르러 내려간다.
        recur(cnt + 1)
        # 다음 숫자를 시도하기 위해 선택을 되돌린다.
        path.pop()
```

그리고 전역 `path` 없이도 구현할 수 있다.

```python
# cnt는 현재 깊이, p는 지금까지 만든 경로를 뜻한다.
def recur2(cnt, p):
    # 2장을 모두 골랐다면 언패킹해서 출력한다.
    if cnt == 2:
        print(*p)
        return 
    
    # 0, 1, 2를 하나씩 뒤에 붙여 새 경로를 만든다.
    for i in range(3):
        # p + [i]는 새 리스트를 만들어 다음 호출로 넘긴다.
        recur2(cnt + 1, p + [i])

# 빈 경로에서 시작한다.
recur2(0, [])
```

#### 코드 흐름 해설

- 첫 번째 버전은 “선택을 직접 펼쳐 쓴 형태”라서 재귀 구조를 눈으로 보기 쉽다.
- 두 번째 버전은 `for`문으로 줄여서 일반화한 형태다.
- 세 번째 버전은 전역 상태 없이 매개변수로 경로를 넘기는 방식이다.

#### 자주 하는 실수 / 디버깅 포인트

- `path.pop()`이 없으면 다음 선택과 이전 선택이 섞인다.
- 전역 리스트를 쓰지 않는 버전에서는 `p.append(i)` 대신 `p + [i]`처럼 새 리스트를 만들어 넘긴다.

### 4-8. 중복을 제거해 순열 만들기

이번에는 같은 숫자를 다시 쓰지 않도록 `used`를 붙인다.

```python
# 현재까지 고른 숫자를 저장하는 리스트다.
path = []
# 사용할 숫자의 종류 수다.
N = 3
# used[i]는 i를 이미 썼는지 기록하는 배열이다.
used = [0] * N

# cnt는 현재 몇 개를 골랐는지 뜻한다.
def recur2(cnt):
    # 2개를 모두 골랐다면 현재 순열을 출력한다.
    if cnt == 2:
        print(*path)
        return
    
    # 0, 1, 2를 차례대로 확인한다.
    for i in range(3):
        # 이미 사용한 숫자라면 건너뛴다.
        if used[i]:
            continue
            
        # 지금 숫자를 사용했다고 표시한다.
        used[i] = 1
        # path에 현재 숫자를 추가한다.
        path.append(i)
        # 다음 자리 선택으로 내려간다.
        recur2(cnt + 1)
        # 돌아오면 path에서 현재 숫자를 제거한다.
        path.pop()
        # 사용 기록도 다시 지워서 다른 경우에 쓸 수 있게 한다.
        used[i] = 0

# 0개 고른 상태에서 시작한다.
recur2(0)
```

강의 후반에 나온 같은 아이디어의 `False/True` 버전도 함께 보면 더 잘 연결된다.

```python
# 현재까지 고른 숫자를 저장할 리스트다.
path = []
# 각 숫자의 사용 여부를 True/False로 기록한다.
used = [False, False, False]

# x는 현재 깊이다.
def KFC(x):
    # 2개를 모두 골랐다면 현재 순열을 출력한다.
    if x == 2:
        print(*path)
        return
    
    # 0, 1, 2를 차례로 보며 아직 안 쓴 숫자만 고른다.
    for i in range(3):
        # 이미 사용한 숫자라면 건너뛴다.
        if used[i] == True:
            continue
        # 사용했다고 표시한다.
        used[i] = True
        # 현재 숫자를 경로에 기록한다.
        path.append(i)
        # 다음 깊이로 내려간다.
        KFC(x + 1)
        # 돌아오면 현재 숫자를 경로에서 제거한다.
        path.pop()
        # 사용 기록도 초기화한다.
        used[i] = False

# 0레벨에서 시작한다.
KFC(0)
```

#### 코드 흐름 해설

- 중복순열 코드에 `used`만 추가하면 순열이 된다.
- 핵심은 **선택 전 체크 → 선택 표시 → 재귀 → 원상복구** 네 단계다.

#### 자주 하는 실수 / 디버깅 포인트

- `used[i] = 0` 또는 `False`로 되돌리는 코드를 빼먹으면 이후 경우가 막힌다.
- `continue` 위치를 잘못 두면 아예 출력이 안 되거나 일부만 나온다.

### 4-9. 주사위 3개를 뽑는 모든 경우 만들기

이 코드는 `1~6` 숫자를 3번 선택하는 중복순열 구조를 좀 더 실전처럼 쓴 예시다.

```python
# 선택 가능한 숫자 목록이다.
arr = [1, 2, 3, 4, 5, 6]
# 총 3번 선택할 것이다.
N = 3

# i는 현재 몇 번 선택했는지, path는 지금까지 고른 숫자다.
def recur(i, path):
    # 3개를 모두 골랐다면 현재 경우를 출력한다.
    if i == N:
        print(path)
        return

    # arr 안에 있는 숫자를 하나씩 현재 위치에 놓아 본다.
    for num in arr:
        # 현재 숫자를 path에 담는다.
        path.append(num)
        # 다음 위치를 고르러 내려간다.
        recur(i + 1, path)
        # 다른 숫자도 놓아 보기 위해 방금 숫자를 다시 뺀다.
        path.pop()

# 아직 아무 숫자도 고르지 않은 상태에서 시작한다.
recur(0, [])
```

#### 코드 흐름 해설

- 이 코드는 `0, 1, 2` 대신 실제 주사위 눈금 `1~6`을 다룬다.
- `path`가 매번 현재 상태를 보여 주기 때문에 완전탐색 문제로 연결하기 좋다.

#### 자주 하는 실수 / 디버깅 포인트

- `path`를 매개변수로 받았다고 해서 `pop()`이 필요 없어지는 것은 아니다.
- 같은 리스트를 재사용하므로 여전히 복구가 필요하다.

### 4-10. 선택한 숫자를 다시 못 고르게 하는 순열 버전

강의 노트에 적힌 형태를 최대한 유지한 순열 예시다.

```python
# 선택 가능한 숫자 목록이다.
arr = [1, 2, 3, 4, 5, 6]
# 총 3개를 고를 것이다.
N = 3

# selected[j]는 arr의 j번 인덱스 숫자를 이미 썼는지 기록한다.
selected = [0] * len(arr)
# selected[1] = 0 이면 arr의 1번 위치 숫자(2)는 아직 안 쓴 상태다.
# selected[2] = 1 이면 arr의 2번 위치 숫자(3)는 이미 쓴 상태다.

# i는 현재 몇 개 골랐는지, path는 지금까지 고른 숫자들이다.
def perm(i, path, selected):
    # 3개를 모두 골랐다면 현재 순열을 출력한다.
    if i == N:
        print(path)
        return
    
    # arr 전체를 돌면서 아직 쓰지 않은 숫자를 찾는다.
    for j in range(len(arr)):
        # arr의 j번 인덱스 숫자를 현재 위치에 놓으려 한다.
        # 원문 필기 흐름을 살리기 위해 설명도 그대로 붙인다.
        if not selected[j]:
            # 아직 쓰지 않은 숫자라면 path에 추가한다.
            path.append(arr[j])
            # 사용했다고 표시한다.
            selected[j] = 1
            # 다음 자리 선택으로 내려간다.
            perm(i + 1, path, selected)
            # 돌아오면 현재 숫자를 path에서 제거한다.
            path.pop()
            # 사용 기록을 지워 다른 경우에서 다시 쓸 수 있게 한다.
            selected[j] = 0

# 0단계, 아직 아무것도 안 고른 상태에서 시작한다.
perm(0, [], selected)
```

⚠️ **주의**  
원래 필기 셀에는 `if not selected:`처럼 적혀 있었는데, 그 줄은 실행 관점에서는 보통 `if not selected[j]:` 의도로 읽는 것이 자연스럽다. 이번 정리본에서는 **강의 의도는 유지하면서, 실제 흐름이 보이도록 필요한 최소한만 바로잡아 주석화**했다.

#### 코드 흐름 해설

- `selected`는 `used`와 같은 역할이다.
- `path`에는 실제 값이 들어가고, `selected`는 인덱스 기준 사용 여부를 기록한다.

#### 자주 하는 실수 / 디버깅 포인트

- `selected[j] = 0`을 빼먹으면 이후 탐색에서 그 숫자를 다시 못 쓴다.
- `selected`는 값이 아니라 **인덱스별 사용 여부**를 관리하는 배열이라는 점을 기억해야 한다.

### 4-11. 완전탐색 문제 1: 주사위 합이 10 이하인 경우 세기

이제 경우를 “만드는 것”에 더해, 조건을 만족하는 경우만 세는 문제로 확장된다.

```python
# 현재까지 선택한 주사위 눈을 저장한다.
path = []
# 조건을 만족하는 경우의 수를 센다.
cnt = 0

# x는 현재 몇 번째 주사위를 골랐는지, sum은 지금까지의 합이다.
def kfc(x, sum):
    global cnt
    # 가지치기: 이미 합이 10을 넘었다면 더 내려갈 필요가 없다.
    if sum > 10:
        return
    
    # 주사위 3개를 모두 골랐다면 조건을 만족하는 경우 하나를 찾은 것이다.
    if x == 3:
        cnt += 1
        return
    
    # 현재 주사위는 1부터 6까지 모두 가능하다.
    for i in range(1, 7):
        # 현재 눈금을 path에 기록한다.
        path.append(i)
        # 다음 단계로 가면서 합도 함께 누적한다.
        kfc(x + 1, sum + i)
        # 다음 경우를 위해 현재 눈금을 제거한다.
        path.pop()

# 시작은 0번째 주사위, 합은 0이다.
kfc(x=0, sum=0)
# 조건을 만족한 총 경우의 수를 출력한다.
print(cnt)
```

#### 코드 흐름 해설

- `sum`이 누적 상태 역할을 한다.
- `sum > 10`이면 더 볼 필요가 없으므로 바로 종료한다.
- 이것이 완전탐색에 가지치기를 붙인 첫 예시다.

#### 자주 하는 실수 / 디버깅 포인트

- `cnt += 1`은 `x == 3`일 때만 해야 한다.
- `sum > 10` 검사보다 늦게 가지치기하면 불필요한 호출이 많아진다.

### 4-12. 완전탐색 문제 2: 같은 카드가 3장 연속으로 나오는 경우

이 코드는 “모든 경우 생성”과 “조건 검사 함수 분리”를 한 번에 보여 준다.

```python
# 선택 가능한 카드 종류다.
card = ['A', 'J', 'Q', 'K']
# 현재까지 뽑은 카드 순서를 저장한다.
path = []
# 조건을 만족하는 경우의 수를 센다.
cnt = 0

# path 안에 같은 카드가 3장 연속인 구간이 있는지 검사한다.
def cont_three():
    # 0, 1, 2번째 카드가 모두 같으면 True를 반환한다.
    if path[0] == path[1] == path[2]:
        return True
    # 1, 2, 3번째 카드가 모두 같으면 True를 반환한다.
    if path[1] == path[2] == path[3]:
        return True
    # 2, 3, 4번째 카드가 모두 같으면 True를 반환한다.
    if path[2] == path[3] == path[4]:
        return True
    # 어느 구간도 해당하지 않으면 False다.
    return False

# lev는 현재 몇 장 뽑았는지 뜻한다.
def permu(lev):
    global cnt
    # 5장을 모두 뽑았다면 연속 3장 조건을 검사한다.
    if lev == 5:
        # 조건을 만족하면 경우의 수를 1 증가시킨다.
        if cont_three():
            cnt += 1
        return
    
    # 현재 자리에 A, J, Q, K 중 하나를 놓아 본다.
    for i in range(4):
        # 현재 카드를 path에 추가한다.
        path.append(card[i])
        # 다음 자리로 내려간다.
        permu(lev + 1)
        # 다음 경우를 위해 현재 카드를 제거한다.
        path.pop()

# 0장 뽑은 상태에서 시작한다.
permu(0)
# 조건을 만족하는 총 경우의 수를 출력한다.
print(cnt)
```

#### 코드 흐름 해설

- `permu()`는 경우 생성 담당이다.
- `cont_three()`는 조건 검사 담당이다.
- 이렇게 역할을 나누면 완전탐색 문제가 훨씬 읽기 쉬워진다.

#### 자주 하는 실수 / 디버깅 포인트

- 조건 검사까지 `permu()` 안에 다 섞어 쓰면 코드가 복잡해진다.
- 먼저 “모든 경우 생성”, 그 다음 “조건 검사”로 분리해서 보는 습관이 중요하다.

### 4-13. Baby-gin은 왜 다음 단계의 대표 문제인가

강의 마지막 Baby-gin은 코드보다 사고 흐름이 더 중요하다.

- 6장의 카드에 대해 가능한 순서를 모두 만들어 본다.
- 앞의 3장과 뒤의 3장이 각각 `run` 또는 `triplet`인지 검사한다.
- 하나라도 만족하면 정답이다.

즉, 지금까지 배운 구조를 그대로 옮기면 된다.

1. **경우를 만든다.**
2. **조건을 검사한다.**
3. **필요하면 가지치기하거나 조기 종료한다.**

이 흐름이 재귀, 순열, 완전탐색을 한 줄로 이어 준다.

## 5. 배운 점 / 느낀 점 / 확장 포인트

이 강의를 통해 가장 크게 배울 수 있는 점은,  
재귀를 “문법”이 아니라 **탐색 구조를 설계하는 도구**로 봐야 한다는 것이다.

처음에는 재귀가 단순히 자기 자신을 다시 호출하는 낯선 문법처럼 보이지만,  
순열과 완전탐색 문제까지 연결해 보면 역할이 훨씬 분명해진다.

- 반복문은 고정된 깊이의 구조에 강하다.
- 재귀는 깊이가 커지거나 구조가 트리처럼 퍼지는 문제에 강하다.
- `path`, `used`, `lev` 같은 상태를 관리하면 경우의 수 생성이 체계화된다.
- 여기에 조건 검사를 붙이면 완전탐색 문제가 된다.
- 조건이 안 되는 경로를 미리 끊으면 가지치기가 된다.

실제로 이 흐름은 코딩테스트에서 아주 자주 등장한다.

- 순열 / 조합 / 부분집합 생성
- DFS / 백트래킹
- 게임판 탐색
- 특정 조건을 만족하는 경우의 수 세기

🧠 **확장 포인트**

1. **부분집합 생성**도 같은 구조로 만들 수 있다.  
   각 원소를 “고른다 / 안 고른다” 두 갈래로 나누면 된다.

2. **조합**은 순열과 달리 순서를 고려하지 않으므로,  
   다음 재귀호출의 시작 인덱스를 조절하는 방식으로 확장된다.

3. **백트래킹**은 완전탐색에 가지치기를 더한 형태로 볼 수 있다.  
   이번 강의의 주사위 합 예시가 그 출발점이다.

## 6. 요약 정리

이 섹션에서는 강의 핵심을 다시 짧게 정리한다.

📌 **핵심**

- 재귀는 **더 작은 같은 문제를 호출**하며 답을 구하는 방식이다.
- 재귀에는 반드시 **기저조건**이 필요하다.
- 재귀 탐색은 보통 **선택 → 재귀호출 → 복구** 패턴으로 작성한다.
- `path`는 지금까지의 선택 기록이고, `used`는 중복 방지 장치다.
- 중복순열은 같은 원소를 여러 번 써도 되고, 순열은 안 된다.
- 완전탐색은 가능한 모든 경우를 시도하는 방법이다.
- 가지치기를 하면 불필요한 경우를 조기에 제거할 수 있다.

🧠 **기억할 것**

- “이 문제의 Level은 몇인가?”
- “각 Level에서 Branch는 몇 개인가?”
- “지금까지 선택한 상태를 무엇으로 저장할 것인가?”
- “언제 멈추고, 언제 복구할 것인가?”

이 네 가지 질문이 재귀/완전탐색 문제를 푸는 기본 출발점이다.
