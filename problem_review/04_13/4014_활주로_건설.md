# 4014. 활주로 건설

- 목표: 각 행과 열에 활주로를 놓을 수 있는지 검사해 가능한 활주로 개수를 구한다.
- 키워드: 시뮬레이션, 구현, 경사로, 배열 검사
- 난이도: 중
- 핵심 알고리즘: 시뮬레이션 / 조건 검사

---

## 1. 문제 이해

N x N 지형에서 각 칸의 높이가 주어진다.  
한 행 또는 한 열이 활주로가 되려면 높이 차이가 0이거나, 높이 차이가 1인 곳에 길이 X의 경사로를 놓을 수 있어야 한다.  
가능한 행과 열의 개수를 구한다.

## 2. 문제를 내 말로 재정의

각 행과 열을 하나의 길로 보고 왼쪽에서 오른쪽으로 검사한다. 높이 차가 0이면 계속 진행하고, 차이가 정확히 1일 때만 길이 `X`의 경사로를 놓을 수 있다.

오르막과 내리막은 확인 방향이 다르다.

- 오르막: 현재 위치 뒤쪽에 같은 높이 칸 `X`개가 필요하다.
- 내리막: 현재 위치 앞쪽에 낮은 높이 칸 `X`개가 필요하다.
- 높이 차가 2 이상이면 즉시 실패한다.

경사로가 겹치면 안 되므로 사용한 칸을 표시하거나, 연속한 평지 길이를 정확히 관리해야 한다. 같은 검사 함수를 행과 열에 재사용하면 중복을 줄일 수 있다.

## 3. 사용된 알고리즘 / 자료구조 개념

### 선형 배열 검사
- 행 하나 또는 열 하나를 1차원 배열로 보고 검사하면 문제가 단순해진다.
- 높이가 올라가는 경우와 내려가는 경우를 따로 처리한다.

### 사용 여부 배열
- 한 칸에 경사로가 중복으로 놓이면 안 된다.
- `used` 배열로 이미 경사로에 사용된 칸을 표시한다.

## 4. 풀이 아이디어 탐색

전체 2차원 지형을 한 번에 처리하려고 하면 헷갈린다.  
활주로는 행 또는 열 단위로만 판단하므로, 한 줄씩 꺼내서 `check_line` 함수로 처리하는 것이 좋다.  

높이 차이가 1보다 크면 바로 불가능하다.  
높이가 1 올라가면 이전 X칸에 경사로가 필요하고, 높이가 1 내려가면 다음 X칸에 경사로가 필요하다.

## 5. 최종 풀이 전략

1. `check_line(line)` 함수를 만든다.
2. 인접한 두 칸의 높이 차이를 확인한다.
3. 차이가 0이면 넘어간다.
4. 차이가 1이면 이전 X칸이 같은 높이이고 미사용인지 확인한다.
5. 차이가 -1이면 다음 X칸이 같은 높이이고 미사용인지 확인한다.
6. 조건을 만족하면 해당 칸들을 사용 처리한다.
7. 모든 행과 열에 대해 검사한다.

## 6. 검증

- 한 줄 검사 비용은 `O(N * X)` 정도로 볼 수 있다.
- 전체 행/열은 `2N`개이므로 충분히 가능하다.
- 공간복잡도는 한 줄 검사마다 `used` 배열 `O(N)`.
- 경사로가 겹치는 경우를 반드시 막아야 한다.

## 7. 구현 포인트

- 높이 차이가 `1`이면 올라가는 경사로, `-1`이면 내려가는 경사로다.
- 올라갈 때는 현재 위치 기준 왼쪽 X칸을 검사한다.
- 내려갈 때는 다음 위치 기준 오른쪽 X칸을 검사한다.
- 범위를 벗어나면 불가능하다.

### 실수 포인트 / 자주 틀리는 이유

- 내려가는 경사로를 놓은 칸이 이후 올라가는 경사로에 다시 사용될 수 없다.
- 높이 차이가 2 이상이면 어떤 경사로로도 해결할 수 없다.
- 행과 열을 모두 검사해야 한다.

## 8. 코드

```python
import sys
input = sys.stdin.readline

def check_line(line):
    used = [False] * N

    for i in range(N - 1):
        diff = line[i + 1] - line[i]

        if diff == 0:
            continue

        # 높이가 1 올라가는 경우: 이전 X칸에 경사로 필요
        if diff == 1:
            for j in range(i, i - X, -1):
                if j < 0 or line[j] != line[i] or used[j]:
                    return False
                used[j] = True

        # 높이가 1 내려가는 경우: 다음 X칸에 경사로 필요
        elif diff == -1:
            for j in range(i + 1, i + 1 + X):
                if j >= N or line[j] != line[i + 1] or used[j]:
                    return False
                used[j] = True

        else:
            return False

    return True

T = int(input())

for tc in range(1, T + 1):
    N, X = map(int, input().split())
    board = [list(map(int, input().split())) for _ in range(N)]

    answer = 0

    for r in range(N):
        if check_line(board[r]):
            answer += 1

    for c in range(N):
        col = [board[r][c] for r in range(N)]
        if check_line(col):
            answer += 1

    print(f"#{tc} {answer}")
```

## 9. 코드 해설

- `check_line`은 한 행 또는 한 열이 활주로가 될 수 있는지만 판단한다.
- `diff == 1`이면 높이가 올라가므로 현재 위치 `i`부터 왼쪽으로 X칸을 확인한다.
- `diff == -1`이면 높이가 내려가므로 다음 위치 `i + 1`부터 오른쪽으로 X칸을 확인한다.
- 조건을 만족한 경사로 칸은 `used`로 표시해 중복 사용을 막는다.
- 모든 행과 열을 `check_line`에 넣고 True인 경우만 카운트한다.

## 10. 회고 및 개선 포인트

이 문제는 조건 분기가 많아서 디버깅이 어려운 편이다.  
행/열을 모두 같은 함수로 처리하면 코드 중복이 줄고, 실수도 줄어든다.

## 11. 한 줄 요약

- 활주로 가능 여부는 한 줄씩 보면서 높이 차이 1이 발생한 지점에 경사로를 놓을 수 있는지만 확인하면 된다.
