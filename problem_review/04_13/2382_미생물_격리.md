# 2382. 미생물 격리

- 목표: 시간마다 미생물 군집을 이동시키고 약품 구역/병합 규칙을 적용해 남은 미생물 수를 구한다.
- 키워드: 시뮬레이션, 딕셔너리, 좌표 이동, 충돌 처리
- 난이도: 중상
- 핵심 알고리즘: 시뮬레이션

---

## 1. 문제 이해

N x N 구역에 여러 미생물 군집이 있다.  
각 군집은 위치, 미생물 수, 이동 방향을 가진다.  
M시간 동안 동시에 이동하며, 가장자리에 도착하면 수가 절반이 되고 방향이 반대로 바뀐다.  
같은 위치에 여러 군집이 모이면 미생물 수는 합쳐지고, 방향은 합쳐지기 전 가장 수가 많던 군집의 방향을 따른다.

## 2. 문제를 내 말로 재정의

이 문제는 결국 **가능한 선택지를 모두 확인하되, 문제 규칙에 맞게 상태를 정확히 갱신하는 문제**입니다.  
겉으로는 조건이 많아 보이지만, 핵심은 다음 질문으로 압축할 수 있습니다.

- 지금 선택해야 하는 것은 무엇인가?
- 선택 후 상태가 어떻게 바뀌는가?
- 언제 정답 후보를 갱신해야 하는가?
- 어떤 경우를 더 탐색하지 않아도 되는가?

## 3. 사용된 알고리즘 / 자료구조 개념

### 동시 이동 시뮬레이션
- 모든 군집은 한 시간마다 동시에 이동한다.
- 한 군집씩 바로 병합하면 동시성이 깨질 수 있으므로, 이동 결과를 임시 저장해야 한다.

### 딕셔너리 병합
- 이동 후 좌표를 key로 사용한다.
- 같은 좌표에 도착한 군집들을 리스트로 모은 뒤 한 번에 병합한다.

## 4. 풀이 아이디어 탐색

군집이 이동한 뒤 같은 칸에 모이는 경우가 핵심이다.  
이동하는 순간 바로 기존 배열에 덮어쓰면 같은 시간에 이동한 다른 군집과 충돌 처리가 꼬일 수 있다.  

따라서 각 시간마다 `moved[(r, c)]`에 도착한 군집들을 모으고, 모든 이동이 끝난 후 좌표별로 병합한다.

## 5. 최종 풀이 전략

1. M번 시간을 반복한다.
2. 각 군집을 방향에 따라 한 칸 이동시킨다.
3. 약품 구역이면 미생물 수를 절반으로 줄이고 방향을 반대로 바꾼다.
4. 이동 결과를 좌표별로 딕셔너리에 저장한다.
5. 같은 좌표에 여러 군집이 있으면 수를 합치고, 가장 큰 군집의 방향을 선택한다.
6. M시간 후 모든 군집의 미생물 수를 합한다.

## 6. 검증

- 시간복잡도는 `O(M * K)` 수준이다.
- 공간복잡도는 매 시간 이동 결과 딕셔너리 `O(K)`.
- 약품 구역에서 미생물 수가 0이 되는 군집은 제거해도 된다.
- 병합 방향은 합쳐진 후의 수가 아니라, 병합 전 가장 큰 군집 기준이다.

## 7. 구현 포인트

- 방향 번호는 문제 기준에 맞춰 처리한다.
- 이동 후 가장자리에 도착했는지 확인한다.
- 같은 좌표 병합 시 `max_count`와 `direction`을 함께 관리한다.

### 실수 포인트 / 자주 틀리는 이유

- 좌표를 이동하기 전에 약품 구역을 검사하면 안 된다.
- 병합 방향을 합산 후 숫자로 판단하면 안 된다.
- 수가 0이 된 군집을 남겨두면 불필요한 계산이 생긴다.

## 8. 코드

```python
import sys
from collections import defaultdict
input = sys.stdin.readline

# 1: 상, 2: 하, 3: 좌, 4: 우
dr = [0, -1, 1, 0, 0]
dc = [0, 0, 0, -1, 1]
opposite = [0, 2, 1, 4, 3]

T = int(input())

for tc in range(1, T + 1):
    N, M, K = map(int, input().split())

    groups = []
    for _ in range(K):
        r, c, count, direction = map(int, input().split())
        groups.append((r, c, count, direction))

    for _ in range(M):
        moved = defaultdict(list)

        for r, c, count, direction in groups:
            nr = r + dr[direction]
            nc = c + dc[direction]

            if nr == 0 or nr == N - 1 or nc == 0 or nc == N - 1:
                count //= 2
                direction = opposite[direction]

            if count > 0:
                moved[(nr, nc)].append((count, direction))

        groups = []

        for (r, c), items in moved.items():
            total = 0
            max_count = -1
            next_direction = 0

            for count, direction in items:
                total += count

                if count > max_count:
                    max_count = count
                    next_direction = direction

            groups.append((r, c, total, next_direction))

    answer = sum(count for _, _, count, _ in groups)

    print(f"#{tc} {answer}")
```

## 9. 코드 해설

- `groups`는 현재 살아 있는 군집 목록이다.
- 한 시간이 지날 때마다 모든 군집을 이동시켜 `moved`에 좌표별로 모은다.
- 약품 구역은 이동 후 좌표가 가장자리인지로 판단한다.
- `items`에 같은 위치로 모인 군집들이 들어 있으므로, 수를 합치고 가장 큰 군집의 방향을 선택한다.
- 마지막에 남은 군집들의 미생물 수를 합산한다.

## 10. 회고 및 개선 포인트

이 문제는 동시 이동과 병합 처리가 핵심이다.  
좌표별로 이동 결과를 모은 뒤 한 번에 처리하는 패턴은 다른 시뮬레이션 문제에도 자주 쓰인다.
