# 4013. 특이한 자석

- 목표: 자석 회전 명령을 순서대로 처리한 뒤 최종 점수를 계산한다.
- 키워드: 시뮬레이션, deque, 연쇄 회전
- 난이도: 중하
- 핵심 알고리즘: 시뮬레이션

---

## 1. 문제 이해

4개의 자석이 있고 각 자석은 8개의 날을 가진다.  
특정 자석을 시계 또는 반시계 방향으로 회전시키면, 맞닿은 날의 극성이 다를 때 인접 자석도 반대 방향으로 회전한다.  
모든 명령을 수행한 뒤 각 자석의 12시 방향 극성으로 점수를 계산한다.

## 2. 문제를 내 말로 재정의

이 문제는 결국 **가능한 선택지를 모두 확인하되, 문제 규칙에 맞게 상태를 정확히 갱신하는 문제**입니다.  
겉으로는 조건이 많아 보이지만, 핵심은 다음 질문으로 압축할 수 있습니다.

- 지금 선택해야 하는 것은 무엇인가?
- 선택 후 상태가 어떻게 바뀌는가?
- 언제 정답 후보를 갱신해야 하는가?
- 어떤 경우를 더 탐색하지 않아도 되는가?

## 3. 사용된 알고리즘 / 자료구조 개념

### 시뮬레이션
- 명령을 하나씩 실제 규칙대로 처리한다.
- 중요한 점은 한 명령에서 회전 여부를 먼저 모두 결정한 뒤, 동시에 회전해야 한다는 것이다.

### deque
- 자석 회전은 맨 앞/뒤 원소를 옮기는 작업이다.
- `collections.deque`의 `rotate`를 사용하면 간단하다.

## 4. 풀이 아이디어 탐색

자석을 하나 회전할 때 바로 옆 자석을 즉시 회전시키면 비교해야 할 극성이 바뀔 수 있다.  
따라서 이번 명령에서 각 자석이 어떤 방향으로 회전할지를 먼저 배열에 저장한다.  

이후 저장된 방향에 따라 4개 자석을 한 번에 회전시키면 된다.

## 5. 최종 풀이 전략

1. 회전 명령 `(자석 번호, 방향)`을 읽는다.
2. `dirs` 배열에 각 자석의 회전 방향을 저장한다.
3. 기준 자석의 왼쪽으로 이동하며 6번 날과 2번 날을 비교한다.
4. 기준 자석의 오른쪽으로 이동하며 2번 날과 6번 날을 비교한다.
5. 회전 방향이 정해진 자석만 회전한다.
6. 모든 명령 후 점수를 계산한다.

## 6. 검증

- 명령 수 K와 자석 수 4가 작아 시간복잡도는 사실상 `O(K)`.
- 공간복잡도는 자석 상태 저장 `O(4 * 8)`.
- 동시에 회전한다는 조건만 지키면 예외 상황이 많지 않다.

## 7. 구현 포인트

- 왼쪽 비교: `magnets[i][6]`과 `magnets[i + 1][2]`.
- 오른쪽 비교: `magnets[i - 1][2]`와 `magnets[i][6]`.
- 방향은 인접 자석으로 갈 때마다 부호가 반대가 된다.
- `deque.rotate(1)`은 오른쪽 회전, `deque.rotate(-1)`은 왼쪽 회전이다.

### 실수 포인트 / 자주 틀리는 이유

- 회전을 먼저 해버리고 다음 자석의 회전 여부를 판단하면 안 된다.
- 자석 번호는 입력에서 1번부터 시작하므로 인덱스 변환이 필요하다.
- 점수 계산은 1, 2, 4, 8점이다.

## 8. 코드

```python
import sys
from collections import deque
input = sys.stdin.readline

T = int(input())

for tc in range(1, T + 1):
    K = int(input())
    magnets = [deque(map(int, input().split())) for _ in range(4)]

    for _ in range(K):
        idx, direction = map(int, input().split())
        idx -= 1

        rotate_dirs = [0] * 4
        rotate_dirs[idx] = direction

        # 왼쪽 자석들 확인
        for i in range(idx - 1, -1, -1):
            if magnets[i][2] != magnets[i + 1][6]:
                rotate_dirs[i] = -rotate_dirs[i + 1]
            else:
                break

        # 오른쪽 자석들 확인
        for i in range(idx + 1, 4):
            if magnets[i - 1][2] != magnets[i][6]:
                rotate_dirs[i] = -rotate_dirs[i - 1]
            else:
                break

        # 동시에 회전
        for i in range(4):
            if rotate_dirs[i] != 0:
                magnets[i].rotate(rotate_dirs[i])

    answer = 0
    for i in range(4):
        if magnets[i][0] == 1:
            answer += 1 << i

    print(f"#{tc} {answer}")
```

## 9. 코드 해설

- 각 명령마다 `rotate_dirs`를 새로 만든다.
- 기준 자석은 입력 방향 그대로 저장한다.
- 왼쪽으로 이동하면서 현재 자석의 2번 날과 오른쪽 자석의 6번 날을 비교한다.
- 오른쪽으로 이동하면서 왼쪽 자석의 2번 날과 현재 자석의 6번 날을 비교한다.
- 비교가 끝난 뒤 `rotate_dirs`에 저장된 값으로 동시에 회전한다.
- 마지막에는 각 자석의 0번 위치가 1이면 점수를 더한다.
