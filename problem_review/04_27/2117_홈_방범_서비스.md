# 2117. 홈 방범 서비스

- 목표: 서비스 비용을 감당할 수 있는 범위에서 가장 많은 집을 포함하는 방범 서비스 영역을 찾는다.
- 키워드: 완전탐색, 맨해튼 거리, 시뮬레이션
- 난이도: 중
- 핵심 알고리즘: 완전탐색

---

## 1. 문제 이해

N x N 도시에서 집의 위치와 집당 지불 비용 M이 주어진다.  
방범 서비스 영역은 마름모 형태이며, 운영 비용은 `K*K + (K-1)*(K-1)`이다.  
손해를 보지 않으면서 서비스할 수 있는 최대 집 수를 구한다.

## 2. 문제를 내 말로 재정의

이 문제는 결국 **가능한 선택지를 모두 확인하되, 문제 규칙에 맞게 상태를 정확히 갱신하는 문제**입니다.  
겉으로는 조건이 많아 보이지만, 핵심은 다음 질문으로 압축할 수 있습니다.

- 지금 선택해야 하는 것은 무엇인가?
- 선택 후 상태가 어떻게 바뀌는가?
- 언제 정답 후보를 갱신해야 하는가?
- 어떤 경우를 더 탐색하지 않아도 되는가?

## 3. 사용된 알고리즘 / 자료구조 개념

### 맨해튼 거리
- 마름모 영역은 중심에서의 맨해튼 거리가 `K - 1` 이하인 칸들의 집합이다.
- 따라서 중심과 K를 정하고 모든 집을 세면 된다.

### 완전탐색
- 가능한 중심은 모든 칸이다.
- 가능한 K도 충분히 작으므로 모든 경우를 확인할 수 있다.

## 4. 풀이 아이디어 탐색

처음에는 실제 마름모 범위를 그리며 탐색할 수 있다.  
하지만 구현이 복잡해질 수 있으므로, 모든 집에 대해 중심과의 맨해튼 거리를 계산하는 방식이 더 안정적이다.  

중심을 모든 칸으로 두고, K를 1부터 N+1까지 늘리며 포함되는 집 수와 수익을 계산한다.

## 5. 최종 풀이 전략

1. 모든 도시 좌표를 서비스 중심 후보로 둔다.
2. K를 1부터 N+1까지 확인한다.
3. 모든 집에 대해 `abs(r-cr) + abs(c-cc) < K`이면 포함한다.
4. 수익 `집 수 * M - 운영비`가 0 이상이면 정답을 갱신한다.

## 6. 검증

- 시간복잡도는 `O(N^2 * N * N^2)` 정도지만 N이 작아 가능하다.
- 집 좌표만 따로 저장하면 조금 더 줄일 수 있다.
- 공간복잡도는 집 좌표 리스트 `O(H)`이다.
- K는 도시를 모두 덮을 수 있도록 `N + 1`까지 확인하는 것이 안전하다.

## 7. 구현 포인트

- 서비스 영역 조건은 맨해튼 거리 `< K` 또는 `<= K - 1`이다.
- 운영 비용 공식은 `K*K + (K-1)*(K-1)`이다.
- 손해를 보지 않는 조건은 `home_count * M - cost >= 0`이다.

### 실수 포인트 / 자주 틀리는 이유

- 최대 집 수를 구하는 것이지 최대 이익을 구하는 문제가 아니다.
- 중심이 집 위치일 필요는 없다. 모든 칸이 중심 후보가 된다.
- K 범위를 너무 작게 잡으면 전체를 덮는 경우를 놓칠 수 있다.

## 8. 코드

```python
import sys
input = sys.stdin.readline

def service_cost(k):
    return k * k + (k - 1) * (k - 1)

T = int(input())

for tc in range(1, T + 1):
    N, M = map(int, input().split())
    city = [list(map(int, input().split())) for _ in range(N)]

    houses = []
    for r in range(N):
        for c in range(N):
            if city[r][c] == 1:
                houses.append((r, c))

    answer = 0

    for cr in range(N):
        for cc in range(N):
            for k in range(1, N + 2):
                count = 0

                for hr, hc in houses:
                    if abs(hr - cr) + abs(hc - cc) < k:
                        count += 1

                if count * M - service_cost(k) >= 0:
                    answer = max(answer, count)

    print(f"#{tc} {answer}")
```

## 9. 코드 해설

- `houses`에 집 좌표만 따로 저장해 불필요한 빈 칸 확인을 줄인다.
- 중심 `(cr, cc)`와 서비스 크기 `k`를 모두 시도한다.
- 어떤 집이 포함되는지는 맨해튼 거리로 판단한다.
- 손해가 아니면 `answer`를 집 수 기준으로 갱신한다.

## 10. 회고 및 개선 포인트

이 문제는 “최대 이익”이 아니라 “손해 보지 않는 최대 집 수”를 구한다는 점이 중요하다.  
조건의 목적을 잘못 읽으면 수익이 큰 경우를 찾다가 오답이 날 수 있다.
