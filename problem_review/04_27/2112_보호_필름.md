# 2112. 보호 필름

- 목표: 최소 몇 개의 행에 약품을 투입해야 모든 열이 성능 기준을 통과하는지 구한다.
- 키워드: 백트래킹, 조합, 가지치기, 완전탐색
- 난이도: 상
- 핵심 알고리즘: DFS / 백트래킹 / 가지치기

---

## 1. 문제 이해

D행 W열의 보호 필름이 있고, 각 셀은 A 또는 B 특성을 가진다.  
각 열마다 같은 특성이 연속으로 K개 이상 존재해야 성능 검사를 통과한다.  
한 행 전체를 A 또는 B로 바꾸는 약품 처리를 할 수 있을 때, 최소 처리 횟수를 구한다.

## 2. 문제를 내 말로 재정의

이 문제는 결국 **가능한 선택지를 모두 확인하되, 문제 규칙에 맞게 상태를 정확히 갱신하는 문제**입니다.  
겉으로는 조건이 많아 보이지만, 핵심은 다음 질문으로 압축할 수 있습니다.

- 지금 선택해야 하는 것은 무엇인가?
- 선택 후 상태가 어떻게 바뀌는가?
- 언제 정답 후보를 갱신해야 하는가?
- 어떤 경우를 더 탐색하지 않아도 되는가?

## 3. 사용된 알고리즘 / 자료구조 개념

### 백트래킹
- 각 행에 대해 세 가지 선택이 있다.
  1. 그대로 둔다.
  2. A로 바꾼다.
  3. B로 바꾼다.
- 모든 선택을 탐색하되, 현재 처리 횟수가 이미 정답 이상이면 중단한다.

### 성능 검사 함수
- 모든 열에 대해 연속된 같은 값이 K개 이상 있는지 확인한다.
- K가 1이면 아무 처리 없이 항상 통과한다.

## 4. 풀이 아이디어 탐색

처음에는 몇 개의 행을 바꿀지 조합으로 고른 뒤 A/B 배치를 다시 고를 수 있다.  
하지만 구현이 길어질 수 있다.  

더 직관적인 방법은 위에서부터 한 행씩 보며 `그대로`, `A`, `B` 세 선택을 DFS로 탐색하는 것이다.  
중간에 처리 횟수가 현재 정답 이상이면 더 볼 필요가 없으므로 가지치기한다.

## 5. 최종 풀이 전략

1. 현재 필름이 성능 검사를 통과하면 정답을 갱신한다.
2. 현재 행 번호가 D에 도달하면 종료한다.
3. 현재 행을 그대로 두고 다음 행으로 간다.
4. 현재 행을 모두 0으로 바꾸고 다음 행으로 간다.
5. 현재 행을 모두 1로 바꾸고 다음 행으로 간다.
6. 바꾼 행은 반드시 원상복구한다.

## 6. 검증

- 최악의 경우 각 행마다 3가지 선택이므로 `O(3^D * D * W)`.
- D가 크지 않아 가지치기를 넣으면 가능하다.
- 공간복잡도는 필름 배열과 재귀 깊이 `O(D * W)`.
- `changed >= answer`이면 더 탐색해도 최소가 될 수 없으므로 중단한다.

## 7. 구현 포인트

- 행을 바꾼 뒤 DFS를 호출하고 반드시 원래 행으로 복구한다.
- `check()`를 DFS 초반에 두면 더 빨리 정답을 찾고 가지치기할 수 있다.
- K가 1이면 바로 0을 출력할 수 있다.

### 실수 포인트 / 자주 틀리는 이유

- 열 기준으로 검사해야 하는데 행 기준으로 착각하기 쉽다.
- 약품 처리는 셀 하나가 아니라 행 전체에 적용된다.
- 복구를 얕은 복사로 잘못하면 원본 행이 깨질 수 있다.

## 8. 코드

```python
import sys
input = sys.stdin.readline

def passed():
    for c in range(W):
        cnt = 1
        ok = False

        for r in range(1, D):
            if film[r][c] == film[r - 1][c]:
                cnt += 1
            else:
                cnt = 1

            if cnt >= K:
                ok = True
                break

        if not ok:
            return False

    return True

def dfs(row, changed):
    global answer

    if changed >= answer:
        return

    if passed():
        answer = changed
        return

    if row == D:
        return

    original = film[row][:]

    # 1. 그대로 두기
    dfs(row + 1, changed)

    # 2. A 약품 투입
    film[row] = [0] * W
    dfs(row + 1, changed + 1)

    # 3. B 약품 투입
    film[row] = [1] * W
    dfs(row + 1, changed + 1)

    film[row] = original

T = int(input())

for tc in range(1, T + 1):
    D, W, K = map(int, input().split())
    film = [list(map(int, input().split())) for _ in range(D)]

    if K == 1:
        print(f"#{tc} 0")
        continue

    answer = K
    dfs(0, 0)

    print(f"#{tc} {answer}")
```

## 9. 코드 해설

- `passed()`는 모든 열이 기준을 만족하는지 검사한다.
- DFS는 `row`번째 행을 어떻게 처리할지 결정한다.
- `changed >= answer`이면 이미 더 좋은 답이 될 수 없으므로 종료한다.
- 현재 상태가 통과하면 더 이상 아래 행을 볼 필요 없이 정답을 갱신한다.
- 행을 A/B로 바꾼 뒤에는 `original`로 복구해야 다음 경우에 영향을 주지 않는다.

## 10. 회고 및 개선 포인트

보호 필름은 A형 대비에서 가지치기 연습용으로 매우 좋다.  
완전탐색 구조는 단순하지만, 검사 위치와 복구 위치를 잘못 잡으면 오답이 나기 쉽다.

## 11. 한 줄 요약

- 각 행을 그대로/A/B 중 하나로 선택하며 DFS를 돌리고, 검사 통과 시 최소 약품 수를 갱신한다.
