# 2383. 점심 식사시간

- 목표: 사람들을 두 계단에 배정했을 때 모든 사람이 내려가는 데 걸리는 최소 시간을 구한다.
- 키워드: DFS, 부분집합, 시뮬레이션, 큐
- 난이도: 상
- 핵심 알고리즘: DFS / 시뮬레이션

---

## 1. 문제 이해

방 안에 사람들과 두 개의 계단이 있다.  
각 사람은 두 계단 중 하나를 선택해 이동하고, 계단 입구에 도착한 뒤 1분 후 내려가기 시작한다.  
계단에는 동시에 최대 3명만 올라갈 수 있고, 내려가는 시간은 계단 길이만큼 걸린다.  
모든 사람이 내려가는 최소 시간을 구한다.

## 2. 문제를 내 말로 재정의

이 문제는 결국 **가능한 선택지를 모두 확인하되, 문제 규칙에 맞게 상태를 정확히 갱신하는 문제**입니다.  
겉으로는 조건이 많아 보이지만, 핵심은 다음 질문으로 압축할 수 있습니다.

- 지금 선택해야 하는 것은 무엇인가?
- 선택 후 상태가 어떻게 바뀌는가?
- 언제 정답 후보를 갱신해야 하는가?
- 어떤 경우를 더 탐색하지 않아도 되는가?

## 3. 사용된 알고리즘 / 자료구조 개념

### 배정 DFS
- 각 사람은 계단 0 또는 계단 1 중 하나를 선택한다.
- 사람 수가 많지 않으므로 `2^P` 배정을 모두 확인할 수 있다.

### 계단 시뮬레이션
- 각 계단에 배정된 사람들의 도착 시간을 정렬한다.
- 계단 정원이 3명이므로 네 번째 사람부터는 앞사람 중 하나가 내려갈 때까지 기다린다.

## 4. 풀이 아이디어 탐색

문제는 두 부분으로 나눌 수 있다.

1. 각 사람을 어느 계단에 보낼지 정한다.
2. 해당 배정에서 각 계단의 소요 시간을 계산한다.

사람 배정은 DFS로 하고, 계단 이용은 도착 시간 정렬 후 완료 시간을 계산하면 된다.

## 5. 최종 풀이 전략

1. 사람 좌표와 계단 좌표/길이를 분리한다.
2. DFS로 각 사람을 0번 또는 1번 계단에 배정한다.
3. 배정이 끝나면 각 계단에 도착하는 시간을 계산한다.
4. 도착 시간 순으로 계단을 이용시킨다.
5. 동시에 3명까지만 가능하므로, 네 번째 이후 사람은 3명 앞 사람의 완료 시간 이후에 시작한다.
6. 두 계단 완료 시간의 최댓값으로 전체 시간을 계산한다.

## 6. 검증

- 사람 수 P에 대해 배정 경우는 `2^P`.
- 각 배정마다 정렬 비용이 붙지만 P가 작아 가능하다.
- 공간복잡도는 배정 배열과 도착 시간 리스트 정도다.
- 도착 후 바로 내려가는 것이 아니라 1분 후 시작한다는 점이 중요하다.

## 7. 구현 포인트

- 이동 시간은 맨해튼 거리이다.
- 계단 시작 시간은 `도착 시간 + 1` 이상이다.
- 같은 계단에서 네 번째 사람부터는 `finish_times[i - 3]` 이후에 시작할 수 있다.

### 실수 포인트 / 자주 틀리는 이유

- 도착 시간과 계단 진입 시간을 혼동하면 1분 차이로 오답이 난다.
- 계단 수용 인원 3명을 고려하지 않으면 안 된다.
- 두 계단 중 늦게 끝나는 시간이 전체 종료 시간이다.

## 8. 코드

```python
import sys
input = sys.stdin.readline

def stair_time(arrivals, length):
    if not arrivals:
        return 0

    arrivals.sort()
    finish_times = []

    for i, arrival in enumerate(arrivals):
        start = arrival + 1

        if i >= 3:
            start = max(start, finish_times[i - 3])

        finish_times.append(start + length)

    return finish_times[-1]

def evaluate():
    arrivals = [[], []]

    for i, stair_idx in enumerate(selected):
        pr, pc = people[i]
        sr, sc, length = stairs[stair_idx]
        dist = abs(pr - sr) + abs(pc - sc)
        arrivals[stair_idx].append(dist)

    time0 = stair_time(arrivals[0], stairs[0][2])
    time1 = stair_time(arrivals[1], stairs[1][2])

    return max(time0, time1)

def dfs(idx):
    global answer

    if idx == len(people):
        answer = min(answer, evaluate())
        return

    selected[idx] = 0
    dfs(idx + 1)

    selected[idx] = 1
    dfs(idx + 1)

T = int(input())

for tc in range(1, T + 1):
    N = int(input())

    people = []
    stairs = []

    for r in range(N):
        row = list(map(int, input().split()))
        for c, value in enumerate(row):
            if value == 1:
                people.append((r, c))
            elif value > 1:
                stairs.append((r, c, value))

    selected = [0] * len(people)
    answer = 10**18

    dfs(0)

    print(f"#{tc} {answer}")
```

## 9. 코드 해설

- `selected[i]`는 i번 사람이 선택한 계단 번호이다.
- DFS는 각 사람을 0번 또는 1번 계단에 배정한다.
- `evaluate()`는 현재 배정에서 두 계단별 도착 시간을 계산한다.
- `stair_time()`은 한 계단에 모인 사람들의 실제 완료 시간을 계산한다.
- `i >= 3`이면 동시에 3명 제한 때문에 3명 앞 사람이 끝난 시간 이후에 시작해야 한다.

## 10. 회고 및 개선 포인트

점심 식사시간은 배정과 시뮬레이션을 분리하는 연습에 좋다.  
한 함수에 모든 것을 넣기보다, 배정 DFS와 계단 시간 계산을 나누면 실수가 줄어든다.
