# 4008. 숫자 만들기

- 목표: 주어진 숫자 순서를 유지하면서 연산자를 배치했을 때 만들 수 있는 최댓값과 최솟값의 차이를 구한다.
- 키워드: DFS, 백트래킹, 완전탐색, 연산자 배치
- 난이도: 중
- 핵심 알고리즘: DFS / 백트래킹

---

## 1. 문제 이해

숫자 N개와 `+`, `-`, `*`, `/` 연산자의 개수가 주어진다.  
숫자의 순서는 바꿀 수 없고, 숫자 사이에 연산자를 하나씩 넣어 계산한다.  
가능한 모든 계산 결과 중 최댓값과 최솟값을 찾고, 두 값의 차이를 출력한다.

## 2. 문제를 내 말로 재정의

이 문제는 결국 **가능한 선택지를 모두 확인하되, 문제 규칙에 맞게 상태를 정확히 갱신하는 문제**입니다.  
겉으로는 조건이 많아 보이지만, 핵심은 다음 질문으로 압축할 수 있습니다.

- 지금 선택해야 하는 것은 무엇인가?
- 선택 후 상태가 어떻게 바뀌는가?
- 언제 정답 후보를 갱신해야 하는가?
- 어떤 경우를 더 탐색하지 않아도 되는가?

## 3. 사용된 알고리즘 / 자료구조 개념

### DFS / 백트래킹
- 연산자를 하나씩 선택하면서 다음 숫자와 계산해 나가는 방식이다.
- 연산자의 총 개수는 `N - 1`개이므로 깊이는 최대 `N - 1`이다.
- 모든 연산자 배치 경우를 확인해야 하므로 DFS가 자연스럽다.

### 정수 나눗셈
- SWEA의 이 문제는 C/C++처럼 음수 나눗셈이 0에 가까운 방향으로 버림 처리된다.
- Python의 `//`는 음수에서 내림이므로 직접 처리해야 한다.

## 4. 풀이 아이디어 탐색

처음에는 연산자 순열을 모두 만들어 계산하는 방법을 떠올릴 수 있다.  
하지만 같은 연산자가 여러 개 있으면 중복 순열이 많이 생긴다.  

따라서 연산자 리스트를 직접 나열하지 않고, 남은 `+`, `-`, `*`, `/` 개수를 관리하며 DFS를 수행한다.  
각 단계에서는 현재까지 계산한 값과 다음 숫자를 이용해 4가지 연산 중 가능한 연산만 선택한다.

## 5. 최종 풀이 전략

1. 첫 번째 숫자를 현재 값으로 시작한다.
2. 두 번째 숫자부터 차례대로 확인한다.
3. 남아 있는 연산자 중 하나를 선택해 현재 값과 다음 숫자를 계산한다.
4. 연산자 개수를 하나 줄이고 다음 깊이로 이동한다.
5. 모든 숫자를 사용하면 최댓값과 최솟값을 갱신한다.

의사코드:

```text
dfs(index, value, plus, minus, mul, div):
    if index == N:
        max_value 갱신
        min_value 갱신
        return

    if plus > 0:
        dfs(index + 1, value + numbers[index], plus - 1, ...)
    ...
```

## 6. 검증

- 시간복잡도: 최악의 경우 연산자 배치 수에 비례한다. 대략 `O(4^(N-1))`로 볼 수 있지만, 실제로는 주어진 연산자 개수 조합만 탐색한다.
- 공간복잡도: 재귀 깊이 `O(N)`.
- N이 크지 않기 때문에 모든 연산자 배치를 탐색해도 가능하다.
- 예외 상황은 음수 나눗셈이다. Python의 `//`를 그대로 쓰면 오답이 날 수 있다.

## 7. 구현 포인트

- `idx`는 이번에 사용할 숫자의 인덱스이다.
- `value`는 지금까지 계산된 누적값이다.
- 연산자 개수는 매개변수로 넘겨 원상복구 코드를 줄인다.
- 나눗셈은 별도 함수로 만들어 실수를 줄인다.

### 실수 포인트 / 자주 틀리는 이유

- `-3 // 2 == -2`이지만 문제에서 원하는 값은 `-1`이다.
- 숫자 순서는 절대 바꾸면 안 된다.
- 최댓값/최솟값 초기값을 충분히 크게 잡아야 한다.

## 8. 코드

```python
import sys
input = sys.stdin.readline

def div_trunc(a, b):
    if a < 0:
        return -((-a) // b)
    return a // b

def dfs(idx, value, plus, minus, mul, div):
    global max_value, min_value

    if idx == N:
        max_value = max(max_value, value)
        min_value = min(min_value, value)
        return

    num = numbers[idx]

    if plus > 0:
        dfs(idx + 1, value + num, plus - 1, minus, mul, div)
    if minus > 0:
        dfs(idx + 1, value - num, plus, minus - 1, mul, div)
    if mul > 0:
        dfs(idx + 1, value * num, plus, minus, mul - 1, div)
    if div > 0:
        dfs(idx + 1, div_trunc(value, num), plus, minus, mul, div - 1)

T = int(input())

for tc in range(1, T + 1):
    N = int(input())
    plus, minus, mul, div = map(int, input().split())
    numbers = list(map(int, input().split()))

    max_value = -10**18
    min_value = 10**18

    dfs(1, numbers[0], plus, minus, mul, div)

    print(f"#{tc} {max_value - min_value}")
```

## 9. 코드 해설

- `div_trunc`는 Python의 음수 나눗셈 차이를 보정한다.
- `dfs(1, numbers[0], ...)`에서 첫 번째 숫자를 이미 사용한 상태로 시작한다.
- DFS 안에서는 남은 연산자 개수가 0보다 큰 경우에만 해당 연산을 선택한다.
- `idx == N`이면 모든 숫자를 사용한 것이므로 계산 결과 하나가 완성된다.
- 완성된 결과로 `max_value`, `min_value`를 갱신한다.

## 10. 회고 및 개선 포인트

이 문제는 백트래킹의 가장 기본적인 형태다.  
핵심은 “연산자 순열을 만들지 않고, 남은 개수만으로 상태를 관리한다”는 점이다.  
비슷한 문제를 만나면 먼저 순서가 고정인지, 선택지만 바뀌는지 확인하면 좋다.

## 11. 한 줄 요약

- 숫자 순서를 유지한 채 남은 연산자 개수로 DFS를 돌리면 모든 계산 결과를 중복 없이 확인할 수 있다.
