# 4012. 요리사

- 목표: 식재료를 두 그룹으로 나누었을 때 두 음식의 맛 차이가 최소가 되도록 한다.
- 키워드: 조합, 백트래킹, 완전탐색, 시너지
- 난이도: 중
- 핵심 알고리즘: 조합 / DFS

---

## 1. 문제 이해

N개의 식재료가 있고, 두 식재료를 함께 사용했을 때의 시너지 값이 주어진다.  
식재료를 정확히 `N/2`개씩 두 음식 A, B로 나누어야 한다.  
각 음식의 맛은 선택된 식재료 쌍의 시너지 합이고, 두 음식의 맛 차이의 최솟값을 구한다.

## 2. 문제를 내 말로 재정의

이 문제는 결국 **가능한 선택지를 모두 확인하되, 문제 규칙에 맞게 상태를 정확히 갱신하는 문제**입니다.  
겉으로는 조건이 많아 보이지만, 핵심은 다음 질문으로 압축할 수 있습니다.

- 지금 선택해야 하는 것은 무엇인가?
- 선택 후 상태가 어떻게 바뀌는가?
- 언제 정답 후보를 갱신해야 하는가?
- 어떤 경우를 더 탐색하지 않아도 되는가?

## 3. 사용된 알고리즘 / 자료구조 개념

### 조합
- A 음식에 들어갈 식재료 `N/2`개를 고르면 나머지는 자동으로 B 음식이 된다.
- 순서는 중요하지 않고 선택 여부만 중요하므로 조합 문제다.

### 백트래킹
- 모든 조합을 만들되, 이미 선택 개수가 `N/2`가 되면 계산한다.
- `0번 식재료`를 A에 고정하면 A/B가 뒤바뀐 중복 경우를 줄일 수 있다.

## 4. 풀이 아이디어 탐색

처음에는 모든 식재료에 대해 A 또는 B를 선택하는 방식으로 생각할 수 있다.  
하지만 A와 B가 바뀐 경우는 같은 분할이다.  

그래서 한쪽 음식 A의 조합만 만들고, 나머지를 B로 처리한다.  
A에 0번 식재료를 고정하면 중복 탐색을 절반 정도 줄일 수 있다.

## 5. 최종 풀이 전략

1. `selected[i]`가 True이면 i번 식재료를 A에 넣는다.
2. A에 `N/2`개가 선택되면 B는 나머지 식재료로 정한다.
3. A 음식과 B 음식의 시너지 합을 각각 계산한다.
4. 두 값의 차이를 정답 후보로 갱신한다.

의사코드:

```text
dfs(start, count):
    if count == N/2:
        taste_A, taste_B 계산
        answer 갱신
        return

    for i in range(start, N):
        selected[i] = True
        dfs(i + 1, count + 1)
        selected[i] = False
```

## 6. 검증

- 시간복잡도: 조합 수 `C(N, N/2)`에 맛 계산 `O(N^2)`이 붙는다.
- 공간복잡도: 선택 배열 `O(N)`, 재귀 깊이 `O(N)`.
- N이 크지 않아 조합 완전탐색이 가능하다.
- A와 B의 중복 분할을 줄이지 않아도 통과 가능하지만, 0번 고정으로 더 안정적이다.

## 7. 구현 포인트

- `selected` 배열 하나로 A/B를 나눈다.
- 맛 계산 시 `i == j`는 제외해도 되고, 입력상 대각선은 보통 0이라 영향이 없다.
- `S[i][j] + S[j][i]`를 모두 더해야 한다는 점을 잊지 않는다.

### 실수 포인트 / 자주 틀리는 이유

- A 음식의 맛만 계산하고 B 음식의 맛을 빼먹으면 안 된다.
- 식재료를 `N/2`개보다 많이 고르지 않도록 가지치기해야 한다.
- 시너지 표는 대칭이 아닐 수 있으므로 양방향 값을 모두 고려해야 한다.

## 8. 코드

```python
import sys
input = sys.stdin.readline

def calc_diff():
    food_a = []
    food_b = []

    for i in range(N):
        if selected[i]:
            food_a.append(i)
        else:
            food_b.append(i)

    taste_a = 0
    taste_b = 0

    for i in range(N // 2):
        for j in range(N // 2):
            taste_a += S[food_a[i]][food_a[j]]
            taste_b += S[food_b[i]][food_b[j]]

    return abs(taste_a - taste_b)

def dfs(start, count):
    global answer

    if count == N // 2:
        answer = min(answer, calc_diff())
        return

    if answer == 0:
        return

    for i in range(start, N):
        selected[i] = True
        dfs(i + 1, count + 1)
        selected[i] = False

T = int(input())

for tc in range(1, T + 1):
    N = int(input())
    S = [list(map(int, input().split())) for _ in range(N)]

    selected = [False] * N

    # A/B가 뒤바뀐 중복을 줄이기 위해 0번 식재료를 A에 고정
    selected[0] = True

    answer = 10**18
    dfs(1, 1)

    print(f"#{tc} {answer}")
```

## 9. 코드 해설

- `selected[0] = True`로 0번 식재료를 A 음식에 고정한다.
- `dfs(start, count)`는 `start` 이후 식재료 중에서 A에 넣을 재료를 고른다.
- `count == N // 2`가 되면 A 음식이 완성되므로 나머지를 B로 보고 차이를 계산한다.
- `calc_diff`는 선택 배열을 기준으로 두 그룹을 만들고, 각 그룹 내부의 모든 시너지 합을 계산한다.
- 정답이 0이면 더 줄일 수 없으므로 빠르게 돌아갈 수 있다.

## 10. 회고 및 개선 포인트

이 문제는 “한 그룹을 고르면 나머지는 자동으로 정해진다”는 관점이 중요하다.  
전체를 두 그룹으로 나누는 문제는 대부분 조합으로 바꿔 생각할 수 있다.

## 11. 한 줄 요약

- 두 음식 중 한쪽에 들어갈 식재료 조합만 고르면 나머지는 자동으로 정해진다.
