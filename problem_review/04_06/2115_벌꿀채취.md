# 2115. 벌꿀채취

- 목표: 두 일꾼이 겹치지 않는 벌통 구간을 골라 얻을 수 있는 최대 수익을 구한다.
- 키워드: 완전탐색, 부분집합, 조합, 최적화
- 난이도: 중상
- 핵심 알고리즘: 부분집합 DFS / 완전탐색

---

## 1. 문제 이해

N x N 벌통에서 두 일꾼이 각각 가로로 연속된 M개의 벌통을 선택한다.  
두 일꾼의 구간은 겹치면 안 된다.  
각 일꾼은 선택한 M개 벌통 중 일부를 골라 채취할 수 있고, 채취량 합은 C를 넘을 수 없다.  
수익은 채취한 꿀 양의 제곱 합이며, 두 일꾼 수익 합의 최댓값을 구한다.

## 2. 문제를 내 말로 재정의

이 문제는 결국 **가능한 선택지를 모두 확인하되, 문제 규칙에 맞게 상태를 정확히 갱신하는 문제**입니다.  
겉으로는 조건이 많아 보이지만, 핵심은 다음 질문으로 압축할 수 있습니다.

- 지금 선택해야 하는 것은 무엇인가?
- 선택 후 상태가 어떻게 바뀌는가?
- 언제 정답 후보를 갱신해야 하는가?
- 어떤 경우를 더 탐색하지 않아도 되는가?

## 3. 사용된 알고리즘 / 자료구조 개념

### 구간 선택
- 일꾼은 가로로 연속된 M칸만 선택할 수 있다.
- 가능한 모든 시작 위치를 후보로 만들 수 있다.

### 부분집합 DFS
- 한 일꾼이 고른 M개의 벌통 안에서 어떤 벌통을 실제로 채취할지 결정해야 한다.
- M이 작으므로 부분집합으로 최대 수익을 계산할 수 있다.

## 4. 풀이 아이디어 탐색

문제는 크게 두 단계로 나눌 수 있다.

1. 각 가능한 M칸 구간에서 얻을 수 있는 최대 수익 계산
2. 서로 겹치지 않는 두 구간을 골라 수익 합 최댓값 계산

이렇게 나누면 두 일꾼을 동시에 복잡하게 생각하지 않아도 된다.

## 5. 최종 풀이 전략

1. 모든 행과 시작 열에 대해 길이 M 구간을 만든다.
2. 각 구간마다 부분집합 DFS로 최대 수익을 구한다.
3. 후보 구간들을 리스트에 저장한다.
4. 후보 두 개를 골라 같은 행에서 겹치는지 확인한다.
5. 겹치지 않으면 두 수익의 합으로 정답을 갱신한다.

## 6. 검증

- 구간 후보 수는 `N * (N - M + 1)`.
- 각 구간의 부분집합 탐색은 `O(2^M)`.
- 후보 쌍 비교는 최대 후보 수의 제곱이지만 N이 작아 가능하다.
- 공간복잡도는 후보 리스트 크기 정도다.

## 7. 구현 포인트

- 같은 행의 두 구간이 겹치는지만 확인하면 된다.
- 다른 행이면 무조건 겹치지 않는다.
- 부분집합 DFS에서는 채취량 합이 C를 넘으면 더 진행하지 않는다.

### 실수 포인트 / 자주 틀리는 이유

- M칸을 선택한 뒤 반드시 그 안에서 다시 일부만 채취할 수 있다는 점을 놓치기 쉽다.
- 두 일꾼의 구간이 같은 행에서 겹치면 안 된다.
- 수익은 꿀 양의 합이 아니라 제곱 합이다.

## 8. 코드

```python
import sys
input = sys.stdin.readline

def best_profit(honeys):
    best = 0

    def dfs(idx, total, profit):
        nonlocal best

        if total > C:
            return

        if idx == M:
            best = max(best, profit)
            return

        # 현재 벌통을 선택하는 경우
        dfs(idx + 1, total + honeys[idx], profit + honeys[idx] ** 2)

        # 현재 벌통을 선택하지 않는 경우
        dfs(idx + 1, total, profit)

    dfs(0, 0, 0)
    return best

def is_not_overlap(a, b):
    r1, c1, _ = a
    r2, c2, _ = b

    if r1 != r2:
        return True

    return c1 + M <= c2 or c2 + M <= c1

T = int(input())

for tc in range(1, T + 1):
    N, M, C = map(int, input().split())
    board = [list(map(int, input().split())) for _ in range(N)]

    candidates = []

    for r in range(N):
        for c in range(N - M + 1):
            honeys = board[r][c:c + M]
            profit = best_profit(honeys)
            candidates.append((r, c, profit))

    answer = 0

    for i in range(len(candidates)):
        for j in range(i + 1, len(candidates)):
            if is_not_overlap(candidates[i], candidates[j]):
                answer = max(answer, candidates[i][2] + candidates[j][2])

    print(f"#{tc} {answer}")
```

## 9. 코드 해설

- `best_profit`는 한 일꾼이 선택한 M칸 안에서 얻을 수 있는 최대 수익을 구한다.
- 부분집합 DFS에서 현재 벌통을 선택하거나 선택하지 않는 두 경우로 나눈다.
- `total > C`가 되면 채취량 제한을 넘으므로 종료한다.
- 모든 후보 구간을 `(행, 시작열, 최대수익)`으로 저장한다.
- 두 후보가 겹치지 않을 때만 수익 합을 계산한다.

## 10. 회고 및 개선 포인트

이 문제는 한 번에 풀려고 하면 복잡하지만, “구간별 최대 수익 계산”과 “두 구간 선택”으로 분리하면 훨씬 단순해진다.  
A형 문제에서 자주 쓰이는 분할 사고 방식이다.
