## 실행과 검증

저장소 루트에서 실행한다. Python 3.12.12에서 다음 풀이 테스트의 9개 테스트 메서드가 통과했다. 각 메서드는 여러 경계 사례·전수 비교 입력을 포함한다.

```powershell
# 이번에 추가한 두 풀이를 실제로 실행한다.
python -B -m unittest discover -s problem_review/10_25 -p 'test_*.py' -v
# 저장소 문서의 링크·코드 펜스·노트 집계를 검사한다.
python scripts/check_notes.py
# Git 변경의 공백 문제를 검사한다.
git diff --check
```

문서 검사와 풀이 실행 검사는 서로 다른 검사다. 작은 입력의 독립 구현 비교와 큰 입력의 일부 사례를 확인했지만, 공식 채점 사이트 제출이나 모든 입력에 대한 성능 보장은 하지 않는다. 기존 23개 노트의 코드를 이번 작업에서 일괄 재검증한 것도 아니다.
