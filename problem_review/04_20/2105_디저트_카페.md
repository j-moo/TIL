# 2105. 디저트 카페

- 목표: 대각선 방향으로 사각형 경로를 만들며 가장 많은 종류의 디저트를 먹을 수 있는 경로를 찾는다.
- 키워드: DFS, 백트래킹, 대각선 이동, 경로 탐색
- 난이도: 상
- 핵심 알고리즘: DFS / 백트래킹

---

## 1. 문제 이해

N x N 카페 지도에서 각 칸에는 디저트 종류 번호가 있다.  
출발점에서 대각선 방향으로 이동해 사각형 모양 경로를 만들고 다시 출발점으로 돌아와야 한다.  
같은 디저트 종류를 두 번 먹을 수 없을 때, 가능한 최대 방문 카페 수를 구한다.

## 2. 문제를 내 말로 재정의

한 카페에서 출발해 대각선 네 방향으로 이동하며 사각형 경로를 만든 뒤 출발점으로 돌아와야 한다. 경로에서 같은 종류의 디저트를 두 번 먹을 수 없다.

DFS에서는 좌표뿐 아니라 현재 진행 방향과 먹은 디저트 집합을 관리한다.

```text
현재 방향으로 계속 이동
또는 다음 대각선 방향으로 한 번 꺾기
→ 범위와 디저트 중복 확인
→ 네 방향을 사용해 출발점으로 돌아오면 길이 갱신
```

아무 방향으로나 꺾게 두면 같은 경로를 여러 번 탐색하고 사각형이 아닌 모양도 만들어진다. 방향 전환을 정해진 순서로만 허용하고, 출발점 선택 범위도 완주 가능한 위치로 제한한다.

## 3. 사용된 알고리즘 / 자료구조 개념

### 방향이 제한된 DFS
- 이동 방향은 대각선 4방향이다.
- 사각형을 만들기 위해 방향 순서를 고정할 수 있다.
  - 우하 → 좌하 → 좌상 → 우상
- 현재 방향으로 계속 가거나, 다음 방향으로 한 번 꺾을 수 있다.

### 방문 디저트 관리
- 칸 방문 여부보다 디저트 종류 중복 여부가 중요하다.
- `visited_dessert` 배열이나 set을 사용한다.

## 4. 풀이 아이디어 탐색

모든 경로를 자유롭게 탐색하면 너무 복잡하다.  
하지만 사각형 경로는 대각선 방향을 일정한 순서로만 꺾는다고 볼 수 있다.  

따라서 시작점마다 DFS를 수행하고, 현재 방향으로 이동하거나 다음 방향으로 꺾는 두 선택만 허용한다.  
출발점으로 돌아왔고 네 번째 방향까지 사용했다면 하나의 사각형이 완성된다.

## 5. 최종 풀이 전략

1. 모든 칸을 시작점으로 잡는다.
2. 시작점의 디저트를 방문 처리한다.
3. 방향 순서는 `[우하, 좌하, 좌상, 우상]`으로 고정한다.
4. DFS에서 현재 방향 그대로 가거나 다음 방향으로 꺾는다.
5. 다음 칸이 시작점이고 방향이 마지막 방향이면 정답을 갱신한다.
6. 디저트 종류가 중복되면 이동하지 않는다.

## 6. 검증

- 시작점이 N^2개이고 DFS가 경로를 탐색하지만 N이 작아 가능하다.
- 공간복잡도는 디저트 방문 배열과 재귀 깊이 정도다.
- 사각형 경로가 최소 4칸 이상이어야 한다.
- 출발점으로 너무 빨리 돌아오는 경우는 제외해야 한다.

## 7. 구현 포인트

- 방향을 마음대로 바꾸면 안 되고, 같은 방향 또는 다음 방향으로만 이동한다.
- 출발점으로 돌아오는 것은 예외적으로 허용한다.
- 디저트 종류가 중복되면 같은 칸이 아니어도 방문할 수 없다.

### 실수 포인트 / 자주 틀리는 이유

- 방향 전환 횟수와 현재 방향 인덱스를 혼동하기 쉽다.
- 시작점으로 돌아오는 조건을 너무 느슨하게 잡으면 잘못된 경로가 정답이 된다.
- `visited` 복구를 빠뜨리면 다른 경로 탐색에 영향을 준다.

## 8. 코드

```python
import sys
input = sys.stdin.readline

dr = [1, 1, -1, -1]
dc = [1, -1, -1, 1]

def dfs(r, c, direction, count):
    global answer

    for nd in (direction, direction + 1):
        if nd >= 4:
            continue

        nr = r + dr[nd]
        nc = c + dc[nd]

        if nr == start_r and nc == start_c and nd == 3 and count >= 4:
            answer = max(answer, count)
            continue

        if 0 <= nr < N and 0 <= nc < N:
            dessert = cafe[nr][nc]

            if not visited[dessert]:
                visited[dessert] = True
                dfs(nr, nc, nd, count + 1)
                visited[dessert] = False

T = int(input())

for tc in range(1, T + 1):
    N = int(input())
    cafe = [list(map(int, input().split())) for _ in range(N)]

    answer = -1
    visited = [False] * 101

    for start_r in range(N):
        for start_c in range(N):
            first = cafe[start_r][start_c]
            visited[first] = True
            dfs(start_r, start_c, 0, 1)
            visited[first] = False

    print(f"#{tc} {answer}")
```

## 9. 코드 해설

- `dr`, `dc`는 사각형을 만들기 위한 대각선 방향 순서이다.
- DFS에서는 현재 방향을 유지하거나 다음 방향으로 꺾을 수 있다.
- `nd == 3`인 상태에서 시작점으로 돌아오면 사각형이 완성된다.
- 출발점으로 돌아오는 경우를 제외하고는 디저트 종류가 중복되면 이동하지 않는다.
- 각 시작점마다 방문 배열을 원상복구하면서 탐색한다.

## 10. 회고 및 개선 포인트

디저트 카페는 DFS 문제지만 방향 제한을 어떻게 모델링하느냐가 핵심이다.  
방향 순서를 고정하고 “유지 또는 다음 방향”만 허용하면 구현이 훨씬 단순해진다.

## 11. 한 줄 요약

- 대각선 사각형은 방향 순서를 고정한 DFS로 탐색하고, 디저트 종류 중복을 막으면 된다.
