# 1949. 등산로 조성

- 목표: 가장 높은 봉우리에서 시작해 한 번의 공사 기회를 활용하여 만들 수 있는 최장 등산로 길이를 구한다.
- 키워드: DFS, 백트래킹, 가지치기, 1회 상태 사용
- 난이도: 상
- 핵심 알고리즘: DFS / 백트래킹

---

## 1. 문제 이해

N x N 지도에 산 높이가 주어진다.  
가장 높은 봉우리 중 하나에서 시작해, 매번 현재보다 낮은 곳으로만 이동할 수 있다.  
단 한 번, 최대 K만큼 한 칸을 깎을 수 있을 때 만들 수 있는 가장 긴 등산로 길이를 구한다.

## 2. 문제를 내 말로 재정의

이 문제는 결국 **가능한 선택지를 모두 확인하되, 문제 규칙에 맞게 상태를 정확히 갱신하는 문제**입니다.  
겉으로는 조건이 많아 보이지만, 핵심은 다음 질문으로 압축할 수 있습니다.

- 지금 선택해야 하는 것은 무엇인가?
- 선택 후 상태가 어떻게 바뀌는가?
- 언제 정답 후보를 갱신해야 하는가?
- 어떤 경우를 더 탐색하지 않아도 되는가?

## 3. 사용된 알고리즘 / 자료구조 개념

### DFS
- 현재 위치에서 상하좌우로 이동 가능한 낮은 칸을 탐색한다.
- 경로 길이의 최댓값을 갱신한다.

### 1회 공사 상태
- 공사를 이미 사용했는지 여부를 `used_cut`으로 관리한다.
- 다음 칸이 현재보다 낮지 않더라도, 깎아서 현재보다 낮게 만들 수 있으면 이동할 수 있다.

## 4. 풀이 아이디어 탐색

가장 높은 봉우리에서 시작해야 하므로 시작 후보는 최고 높이 칸들이다.  
DFS를 하면서 다음 칸이 낮으면 그대로 이동한다.  
다음 칸이 높거나 같아도 아직 공사를 쓰지 않았고, 최대 K만큼 깎아 현재보다 낮게 만들 수 있으면 그 칸을 `현재 높이 - 1`로 임시 변경하고 이동한다.

## 5. 최종 풀이 전략

1. 지도에서 최대 높이를 찾는다.
2. 최대 높이인 모든 칸을 시작점으로 DFS를 실행한다.
3. 다음 칸이 현재보다 낮으면 이동한다.
4. 다음 칸이 낮지 않지만 공사를 쓰면 낮아질 수 있으면 높이를 임시로 깎고 이동한다.
5. DFS가 끝나면 깎은 높이를 원상복구한다.
6. 방문 배열로 같은 경로에서 중복 방문을 막는다.

## 6. 검증

- 각 시작점에서 DFS를 수행한다.
- N이 작고 이동 조건이 제한되어 완전탐색 가능하다.
- 공간복잡도는 방문 배열과 재귀 깊이 `O(N^2)`.
- 한 번 깎은 높이는 반드시 원상복구해야 한다.

## 7. 구현 포인트

- 깎을 때는 많이 깎는 것이 아니라 `현재 높이 - 1`까지만 깎는 것이 충분하다.
- 공사 가능 조건은 `next_height - K < current_height`이다.
- 가장 높은 봉우리가 여러 개일 수 있으므로 모두 시작점으로 써야 한다.

### 실수 포인트 / 자주 틀리는 이유

- 공사를 여러 번 쓰면 안 된다.
- 깎은 높이를 복구하지 않으면 다음 경로 탐색이 오염된다.
- 시작점은 아무 곳이 아니라 최고 높이 봉우리다.

## 8. 코드

```python
import sys
input = sys.stdin.readline

dr = [-1, 1, 0, 0]
dc = [0, 0, -1, 1]

def dfs(r, c, length, used_cut):
    global answer

    answer = max(answer, length)

    for d in range(4):
        nr = r + dr[d]
        nc = c + dc[d]

        if not (0 <= nr < N and 0 <= nc < N):
            continue

        if visited[nr][nc]:
            continue

        if mountain[nr][nc] < mountain[r][c]:
            visited[nr][nc] = True
            dfs(nr, nc, length + 1, used_cut)
            visited[nr][nc] = False

        elif not used_cut and mountain[nr][nc] - K < mountain[r][c]:
            original = mountain[nr][nc]
            mountain[nr][nc] = mountain[r][c] - 1

            visited[nr][nc] = True
            dfs(nr, nc, length + 1, True)
            visited[nr][nc] = False

            mountain[nr][nc] = original

T = int(input())

for tc in range(1, T + 1):
    N, K = map(int, input().split())
    mountain = [list(map(int, input().split())) for _ in range(N)]

    max_height = max(max(row) for row in mountain)
    starts = []

    for r in range(N):
        for c in range(N):
            if mountain[r][c] == max_height:
                starts.append((r, c))

    answer = 0

    for r, c in starts:
        visited = [[False] * N for _ in range(N)]
        visited[r][c] = True
        dfs(r, c, 1, False)

    print(f"#{tc} {answer}")
```

## 9. 코드 해설

- 최고 높이를 찾고, 같은 높이의 모든 칸을 시작점으로 저장한다.
- DFS는 현재 위치, 길이, 공사 사용 여부를 인자로 받는다.
- 다음 칸이 낮으면 그대로 이동한다.
- 다음 칸이 낮지 않아도 `K`만큼 안에서 깎아 현재보다 낮게 만들 수 있으면 임시로 깎는다.
- 이동 후에는 방문 상태와 높이를 모두 복구한다.

## 10. 회고 및 개선 포인트

이 문제는 “특수 기회를 한 번만 사용한다”는 상태 관리가 중요하다.  
`used_cut`처럼 기회 사용 여부를 상태로 들고 다니는 패턴은 다른 DFS 문제에서도 자주 나온다.
