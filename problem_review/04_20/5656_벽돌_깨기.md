# 5656. 벽돌 깨기

- 목표: N개의 구슬을 떨어뜨려 벽돌을 최대한 많이 제거했을 때 남은 벽돌 수의 최솟값을 구한다.
- 키워드: DFS, 시뮬레이션, BFS, 중력 처리
- 난이도: 상
- 핵심 알고리즘: DFS / BFS / 시뮬레이션

---

## 1. 문제 이해

W x H 격자에 벽돌들이 있고, 각 벽돌 숫자는 폭발 범위를 의미한다.  
구슬을 한 열에 떨어뜨리면 가장 위의 벽돌이 깨지고, 그 벽돌의 숫자만큼 상하좌우 연쇄 폭발이 일어난다.  
폭발 후 벽돌은 아래로 떨어진다.  
N개의 구슬을 떨어뜨렸을 때 남은 벽돌 수의 최솟값을 구한다.

## 2. 문제를 내 말로 재정의

이 문제는 결국 **가능한 선택지를 모두 확인하되, 문제 규칙에 맞게 상태를 정확히 갱신하는 문제**입니다.  
겉으로는 조건이 많아 보이지만, 핵심은 다음 질문으로 압축할 수 있습니다.

- 지금 선택해야 하는 것은 무엇인가?
- 선택 후 상태가 어떻게 바뀌는가?
- 언제 정답 후보를 갱신해야 하는가?
- 어떤 경우를 더 탐색하지 않아도 되는가?

## 3. 사용된 알고리즘 / 자료구조 개념

### DFS
- 각 구슬은 W개의 열 중 하나에 떨어뜨릴 수 있다.
- N번 선택해야 하므로 `W^N` 경우를 DFS로 탐색한다.

### BFS 폭발
- 벽돌 하나가 깨지면 범위 내 벽돌들이 연쇄적으로 깨진다.
- 큐를 사용해 폭발을 처리하면 안정적이다.

### 중력 처리
- 폭발 후 각 열의 벽돌을 아래에서부터 다시 쌓는다.

## 4. 풀이 아이디어 탐색

문제는 구슬을 어느 열에 떨어뜨릴지 선택하는 완전탐색과, 선택 후 보드 상태를 갱신하는 시뮬레이션으로 나뉜다.  

DFS에서 각 열을 선택하고, 보드를 복사해 구슬을 떨어뜨린 결과를 만든다.  
결과 보드로 다음 구슬을 처리한다.  
구슬을 모두 사용하거나 벽돌이 0개가 되면 정답을 갱신한다.

## 5. 최종 풀이 전략

1. 현재 보드에서 남은 벽돌 수를 센다.
2. 벽돌이 0개이면 정답은 0이다.
3. 구슬을 모두 사용하면 남은 벽돌 수로 정답을 갱신한다.
4. 각 열에 구슬을 떨어뜨리는 경우를 시도한다.
5. 해당 열의 첫 번째 벽돌을 찾아 BFS로 폭발시킨다.
6. 폭발 후 중력을 적용한다.
7. 다음 DFS로 이동한다.

## 6. 검증

- 시간복잡도는 대략 `O(W^N * H * W)` 이상의 시뮬레이션 비용이 든다.
- N과 W가 제한되어 있어 가지치기와 복사를 잘 사용하면 가능하다.
- 공간복잡도는 보드 복사 `O(HW)`와 큐 정도다.
- 정답이 0이 되면 더 탐색할 필요가 없다.

## 7. 구현 포인트

- 입력은 보통 `N W H` 순서이다.
- 보드 크기는 H행 W열이다.
- 폭발 범위가 1이면 자기 자신만 깨진다.
- 빈 열에 구슬을 떨어뜨리는 경우는 상태가 변하지 않는다.

### 실수 포인트 / 자주 틀리는 이유

- W와 H 순서를 헷갈리기 쉽다.
- 폭발 중 같은 벽돌을 여러 번 큐에 넣지 않도록 깨질 때 0으로 만든다.
- 폭발 후 중력 처리를 반드시 해야 한다.
- 보드를 복사하지 않고 수정하면 다른 DFS 분기에 영향을 준다.

## 8. 코드

```python
import sys
from collections import deque
from copy import deepcopy
input = sys.stdin.readline

dr = [-1, 1, 0, 0]
dc = [0, 0, -1, 1]

def count_bricks(board):
    total = 0
    for r in range(H):
        for c in range(W):
            if board[r][c]:
                total += 1
    return total

def apply_gravity(board):
    for c in range(W):
        stack = []

        for r in range(H - 1, -1, -1):
            if board[r][c]:
                stack.append(board[r][c])

        for r in range(H - 1, -1, -1):
            if stack:
                board[r][c] = stack.pop(0)
            else:
                board[r][c] = 0

def break_bricks(board, col):
    target_row = -1

    for r in range(H):
        if board[r][col]:
            target_row = r
            break

    if target_row == -1:
        return board

    q = deque()
    q.append((target_row, col, board[target_row][col]))
    board[target_row][col] = 0

    while q:
        r, c, power = q.popleft()

        for d in range(4):
            for step in range(1, power):
                nr = r + dr[d] * step
                nc = c + dc[d] * step

                if not (0 <= nr < H and 0 <= nc < W):
                    break

                if board[nr][nc]:
                    q.append((nr, nc, board[nr][nc]))
                    board[nr][nc] = 0

    apply_gravity(board)
    return board

def dfs(depth, board):
    global answer

    remain = count_bricks(board)
    answer = min(answer, remain)

    if answer == 0:
        return

    if depth == N:
        return

    for col in range(W):
        next_board = deepcopy(board)
        next_board = break_bricks(next_board, col)
        dfs(depth + 1, next_board)

T = int(input())

for tc in range(1, T + 1):
    N, W, H = map(int, input().split())
    origin = [list(map(int, input().split())) for _ in range(H)]

    answer = count_bricks(origin)
    dfs(0, origin)

    print(f"#{tc} {answer}")
```

## 9. 코드 해설

- `dfs(depth, board)`는 지금까지 `depth`개의 구슬을 사용한 상태이다.
- 현재 남은 벽돌 수를 세어 정답을 갱신한다.
- 각 열에 대해 보드를 복사한 뒤 구슬을 떨어뜨린다.
- `break_bricks`는 해당 열의 첫 벽돌을 찾고 BFS로 연쇄 폭발을 처리한다.
- 폭발한 벽돌은 즉시 0으로 바꿔 중복 처리를 막는다.
- 폭발이 끝나면 `apply_gravity`로 열마다 벽돌을 아래로 떨어뜨린다.
