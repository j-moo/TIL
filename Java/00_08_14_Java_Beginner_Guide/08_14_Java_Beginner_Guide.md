# Java를 처음 배우는 사람을 위한 학습 안내서

- 학습 목표: Java를 한 번도 접하지 않은 사람이 코드가 실행되는 과정과 핵심 용어를 먼저 이해하고, 이 저장소의 Java 노트를 알맞은 순서로 학습한다.
- 핵심 키워드: JDK, JVM, 컴파일, 클래스, `main`, 변수, 조건문, 반복문, 배열, 객체, 예외, 컬렉션, 제네릭
- 중요도: 매우 높음. 세부 문법보다 먼저 전체 지도를 알면 새로운 용어가 나와도 현재 배우는 위치를 잃지 않는다.
- 권장 대상: 프로그래밍 자체가 처음이거나, 다른 언어는 배웠지만 Java는 처음인 학습자

---

## 1. Java를 배우기 전에 알아둘 한 가지

프로그래밍은 컴퓨터가 수행할 일을 **정확한 순서와 규칙으로 적는 활동**이다. Java는 그 명령을 작성하기 위한 프로그래밍 언어 중 하나다.

처음에는 다음 코드가 기호 덩어리처럼 보일 수 있다.

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("안녕하세요");
    }
}
```

지금 모든 단어를 외울 필요는 없다. 우선 다음처럼 읽으면 된다.

```text
Hello라는 프로그램의 시작점에서
화면에 "안녕하세요"를 출력한다.
```

Java 학습은 낯선 단어를 한 번에 암기하는 과정이 아니다. 작은 코드를 직접 실행하고, 값 하나를 바꾸고, 오류를 읽으면서 각 문법의 역할을 연결하는 과정이다.

## 2. Java 코드는 어떻게 실행될까

Java 소스 파일은 컴퓨터가 곧바로 실행하는 파일이 아니다.

```text
Hello.java
   │ javac로 컴파일
   ▼
Hello.class
   │ JVM이 실행
   ▼
화면에 결과 출력
```

각 용어의 역할은 다음과 같다.

| 용어 | 쉬운 설명 | 하는 일 |
| --- | --- | --- |
| JDK | Java 개발 도구 상자 | 컴파일러와 실행 도구를 제공한다. |
| `javac` | 번역기 | `.java`를 JVM이 이해할 `.class`로 컴파일한다. |
| JVM | Java 실행 기계 | `.class`의 바이트코드를 현재 운영체제에서 실행한다. |
| JRE | 실행에 필요한 환경 | JVM과 실행 라이브러리를 포함한다. 현대 JDK 사용자는 보통 JDK를 설치해 개발한다. |

명령줄에서 직접 실행하면 두 단계가 분명하게 보인다.

```bash
javac Hello.java
java Hello
```

IDE의 실행 버튼도 내부적으로는 이 컴파일과 실행 과정을 대신 수행한다.

## 3. 첫 코드를 한 줄씩 읽기

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("안녕하세요");
    }
}
```

### 3.1 `public class Hello`

Java 코드는 기본적으로 클래스라는 틀 안에 작성한다. `Hello`는 클래스 이름이며, `public class Hello`가 있는 파일 이름은 `Hello.java`여야 한다.

### 3.2 `main`

JVM이 프로그램을 시작할 때 찾는 진입점이다. 처음에는 `public static void main(String[] args)` 전체를 시작 버튼의 정해진 모양으로 받아들여도 된다. `public`, `static`, `void`, 배열은 뒤의 노트에서 각각 이해한다.

### 3.3 `System.out.println`

괄호 안의 값을 콘솔에 출력한 뒤 줄을 바꾼다.

```java
System.out.println("첫 번째 줄");
System.out.println(10 + 20);
```

실행 결과:

```text
첫 번째 줄
30
```

### 3.4 중괄호와 세미콜론

중괄호 `{ }`는 코드의 범위를 묶고, 세미콜론 `;`은 하나의 명령문이 끝났음을 표시한다.

```java
if (true) {                    // 범위 시작
    System.out.println("실행"); // 명령문 끝
}                              // 범위 끝
```

## 4. Java 학습의 큰 지도

Java의 주요 개념은 따로 떨어져 있지 않다.

```text
실행 환경
  ↓
값과 변수
  ↓
조건문과 반복문
  ↓
배열·문자열·컬렉션
  ↓
클래스와 객체
  ↓
상속·인터페이스·다형성
  ↓
예외·입출력·제네릭
  ↓
람다·스트림·스레드
```

아래에서는 각 단계가 어떤 질문에 답하는지 살펴본다.

### 4.1 변수: 값을 기억하려면 어떻게 할까

```java
String name = "민지";
int age = 20;
boolean beginner = true;
```

변수는 값을 다시 사용하기 위해 붙인 이름이다. Java는 변수에 어떤 종류의 값이 들어가는지 타입으로 먼저 선언한다.

```text
int age = 20;
│   │     └─ 저장할 값
│   └─────── 변수 이름
└─────────── 값의 타입
```

### 4.2 조건문: 상황에 따라 다른 일을 하려면 어떻게 할까

```java
if (age >= 20) {
    System.out.println("성인입니다.");
} else {
    System.out.println("미성년자입니다.");
}
```

조건식의 결과는 `true` 또는 `false`다. `if`는 참인 경로를, `else`는 거짓인 경로를 실행한다.

### 4.3 반복문: 같은 일을 여러 번 하려면 어떻게 할까

```java
for (int i = 1; i <= 3; i++) {
    System.out.println(i);
}
```

반복문은 복사해 붙인 코드를 하나의 규칙으로 줄인다. 위 코드는 1, 2, 3을 차례로 출력한다.

### 4.4 배열과 컬렉션: 여러 값을 함께 다루려면 어떻게 할까

```java
int[] scores = {80, 90, 100};

for (int score : scores) {
    System.out.println(score);
}
```

배열은 같은 타입의 값을 정해진 크기로 묶는다. 크기를 유연하게 바꾸거나 키로 값을 찾으려면 `ArrayList`, `HashMap`, `HashSet` 같은 컬렉션을 사용한다.

### 4.5 클래스와 객체: 관련된 값과 기능을 묶으려면 어떻게 할까

```java
class Student {
    String name;
    int score;

    void introduce() {
        System.out.println(name + ": " + score);
    }
}
```

클래스는 어떤 값과 기능을 가질지 정한 설계다. `new Student()`로 실제 객체를 만든다.

```java
Student student = new Student();
student.name = "민지";
student.score = 90;
student.introduce();
```

### 4.6 예외: 실패할 수 있는 코드는 어떻게 다룰까

파일이 없거나, 숫자로 바꿀 수 없는 문자열을 받거나, 네트워크 연결이 끊길 수 있다. 예외 처리는 실패를 숨기는 문법이 아니라 실패했을 때 프로그램이 어떻게 행동할지 정하는 방법이다.

```java
try {
    int number = Integer.parseInt("abc");
} catch (NumberFormatException e) {
    System.out.println("숫자 형식이 아닙니다.");
}
```

### 4.7 제네릭: 컬렉션에 담을 타입을 어떻게 약속할까

```java
List<String> names = new ArrayList<>();
names.add("민지");
// names.add(10); // 컴파일 오류
```

`<String>`은 이 목록에 문자열만 담겠다는 타입 계약이다. 잘못된 값을 실행 전에 발견하고, 꺼낸 값을 강제 변환하지 않게 해 준다.

## 5. 처음 공부할 때 권장하는 방법

### 5.1 코드를 직접 입력한다

복사만 하면 괄호와 세미콜론의 역할을 놓치기 쉽다. 짧은 예제는 직접 입력하고 실행한다.

### 5.2 한 번에 하나만 바꾼다

```java
int count = 3;
```

`3`을 `0`, `-1`, `10`으로 바꿔 결과를 본다. 한 번에 여러 부분을 바꾸면 무엇 때문에 결과가 달라졌는지 알기 어렵다.

### 5.3 오류 메시지의 첫 원인을 읽는다

오류가 여러 줄 나와도 가장 처음 발생한 의미 있는 오류부터 본다.

```java
int age = "스무 살";
```

```text
incompatible types: String cannot be converted to int
```

이 메시지는 문자열을 `int` 변수에 넣으려 했다는 뜻이다. 오류를 없애는 것보다 “내가 정한 타입 계약과 어떤 값이 충돌했는가”를 찾는다.

### 5.4 손으로 실행 순서를 적는다

반복문이 헷갈리면 표를 만든다.

| 반복 시작 전 `i` | 조건 `i <= 3` | 출력 | 증가 후 `i` |
| ---: | --- | ---: | ---: |
| 1 | 참 | 1 | 2 |
| 2 | 참 | 2 | 3 |
| 3 | 참 | 3 | 4 |
| 4 | 거짓 | 없음 | 종료 |

### 5.5 예상하고 실행한다

실행 버튼을 누르기 전에 결과를 한 줄이라도 예상한다. 예상과 실제가 다를 때 가장 많이 배운다.

## 6. 자주 만나는 초보자 질문

### 6.1 모든 문법을 외워야 하나

아니다. 자주 쓰는 구조는 반복하면서 자연스럽게 익힌다. 처음에는 “어떤 문제에 어떤 문법을 찾아야 하는지”를 아는 것이 더 중요하다.

### 6.2 `=`와 `==`는 왜 다른가

`=`는 오른쪽 값을 왼쪽 변수에 저장하는 대입이고, `==`는 두 값이 같은지 비교한다.

```java
int age = 20;
System.out.println(age == 20); // true
```

문자열 내용 비교에는 보통 `equals()`를 사용한다.

```java
String name = "민지";
System.out.println(name.equals("민지"));
```

### 6.3 객체 변수에는 객체가 그대로 들어 있나

객체 타입 변수에는 객체를 가리키는 참조가 들어간다고 이해한다.

```java
Student first = new Student();
Student second = first;
```

`first`와 `second`는 서로 다른 두 객체가 아니라 같은 객체를 가리킨다.

### 6.4 `null`은 0이나 빈 문자열인가

아니다. `null`은 참조 변수가 현재 어떤 객체도 가리키지 않는다는 뜻이다. `null`에서 메서드를 호출하면 `NullPointerException`이 발생한다.

### 6.5 검색해서 나온 오래된 코드도 사용해도 되나

Java의 기초 문법은 안정적이지만 API와 권장 방식은 달라질 수 있다. 코드의 Java 버전과 공식 문서를 확인하고, 현재 프로젝트에서 컴파일해 본다.

## 7. 이 저장소의 권장 학습 순서

처음 학습한다면 [Java 학습 로드맵](../README.md)의 `기초 → 데이터 묶기 → 객체지향 → 프로그램 경계 → 심화` 순서로 읽는다.

각 노트는 다음 방식으로 활용한다.

1. `들어가며`에서 해결할 문제를 읽는다.
2. `핵심 개념`에서 용어의 관계를 파악한다.
3. 코드 실행 결과를 먼저 예상한다.
4. 코드를 직접 실행하고 값을 하나씩 바꾼다.
5. `헷갈리기 쉬운 부분`과 복습 문제로 이해를 확인한다.

## 8. 첫 주 학습 예시

| 차시 | 학습 내용 | 작은 목표 |
| ---: | --- | --- |
| 1 | 실행 환경과 첫 프로그램 | 직접 컴파일하고 출력 문장을 바꾼다. |
| 2 | 변수와 연산자 | 이름, 나이, 평균을 변수로 표현한다. |
| 3 | 조건문 | 점수에 따라 등급을 출력한다. |
| 4 | 반복문 | 1부터 100까지 합을 구한다. |
| 5 | 문자열과 배열 | 여러 이름을 순회해 출력한다. |
| 6 | 메서드 | 반복되는 계산을 이름 있는 기능으로 분리한다. |
| 7 | 복습 | 설명 없이 작은 성적 계산 프로그램을 만든다. |

진도보다 중요한 것은 이전 코드를 보지 않고 핵심 구조를 다시 만들 수 있는지다.

## 9. 입문 체크리스트

- [ ] `.java`와 `.class`의 차이를 설명할 수 있다.
- [ ] JDK, 컴파일러, JVM의 역할을 구분할 수 있다.
- [ ] `main`이 프로그램의 시작점이라는 것을 안다.
- [ ] 변수의 타입, 이름, 값을 구분할 수 있다.
- [ ] 조건문과 반복문이 해결하는 문제를 설명할 수 있다.
- [ ] 배열 인덱스가 0부터 시작함을 안다.
- [ ] 클래스와 객체가 같은 말이 아님을 설명할 수 있다.
- [ ] 문자열 내용 비교에 `equals()`를 사용할 수 있다.
- [ ] 오류 메시지를 숨기지 않고 첫 원인을 읽어 본다.
- [ ] 코드를 실행하기 전에 결과를 예상하는 습관을 들인다.
